    Classification#

    When the output is a category, the mean squared error no longer makes sense. This page introduces the error rate, the ideal (but unreachable) Bayes classifier, and a first practical method, \(K\)-nearest neighbours.

    The error rate#

    For a category, “measured minus predicted” has no meaning: faulty minus healthy is not a number, so there is nothing to square. Instead we count the mistakes. The error rate is the fraction of wrong labels:

    \[ \text{error rate} = \frac1n \sum_{i=1}^{n} I\bigl(y_i \neq \hat y_i\bigr). \]

    \(I(\cdot)\) is the indicator function: it equals 1 if the statement in brackets is true and 0 if it is false. For each observation, \(I(y_i \neq \hat y_i)\) is 1 for a wrong label and 0 for a right one. The sum therefore counts the mistakes, and dividing by \(n\) turns the count into a fraction. The accuracy, the fraction labelled correctly, is one minus the error rate.

    Example. A model labels 10 motors and gets 2 of them wrong. The error rate is \(2/10 = 0.2\) and the accuracy is \(1 - 0.2 = 0.8\).

    As with the MSE, what matters is the test error rate, measured on new observations.

    The Bayes classifier#

    Suppose we knew, for every possible input \(x_0\), the probability of each class: \(\Pr(Y = j \mid X = x_0)\), read “the probability that the class is \(j\), given that the input is \(x_0\)”. The Bayes classifier assigns \(x_0\) to the class with the largest such probability.

    It has the lowest error rate any classifier can achieve, called the Bayes error rate, because it always picks the most probable class. The Bayes error rate plays the role that the irreducible error \(\operatorname{Var}(\varepsilon)\) plays in regression: no classifier can beat it.

    Example. A motor vibrates at 6 mm/s. Suppose that of all motors vibrating at 6 mm/s, 80% are faulty: \(\Pr(\text{faulty} \mid 6\text{ mm/s}) = 0.8\) and \(\Pr(\text{healthy} \mid 6\text{ mm/s}) = 0.2\). The Bayes classifier says faulty. Labelling all such motors faulty is wrong 20% of the time, and no rule that sees only the vibration level can do better.

    In practice we never know these probabilities, so the Bayes classifier is an ideal to approach, not a method we can use. (In a simulation we choose the probabilities ourselves, so there we can compare a method against it.)

    \(K\)-nearest neighbours (KNN)#

    \(K\)-nearest neighbours estimates the unknown class probabilities from the training data near \(x_0\):

    1. Find the \(K\) training points closest to \(x_0\). Call this set \(\mathcal N_0\).
    2. Estimate the probability of each class \(j\) by the fraction of these neighbours that belong to it: \[ \Pr(Y = j \mid X = x_0) \approx \frac1K \sum_{i \in \mathcal N_0} I(y_i = j). \] The sum counts how many of the \(K\) neighbours are in class \(j\).
    3. Predict the most common class among the neighbours.

    Example. With \(K = 5\), suppose 4 of the 5 nearest motors are faulty. The indicator is 1 for the four faulty neighbours and 0 for the healthy one, so the sum is 4 and \(\Pr(\text{faulty}) \approx \tfrac15 \times 4 = 0.8\). Predict faulty.

    Choosing \(K\). \(K\) controls the flexibility of the method.

    • Small \(K\) (1 or 3) gives a flexible, noisy boundary between the classes and may overfit. With \(K = 1\) each new point takes the label of its single nearest neighbour, so the boundary follows every noisy point. The training error is then zero (each training point is its own nearest neighbour), but the test error is not.
    • Large \(K\) takes the vote over a wide region, which makes the boundary smooth, and possibly too smooth to follow the real shape: it may underfit.

    \(K\) plays the same role as the polynomial degree on the previous page, in reverse: a small \(K\) is flexible. As with the degree, \(K\) is chosen by the test error.

    KNN is non-parametric: it keeps the training data and assumes no formula for \(f\).

    Example: KNN by hand#

    Six machines have vibration levels (mm/s) and known states:

    vibration1.01.52.23.03.84.5
    statehealthyhealthyfaultyhealthyfaultyfaulty

    Classify a new machine with vibration 2.5 mm/s using KNN with \(K = 1\) and with \(K = 3\).

    Solution triple-click to reveal

    Distances from 2.5: 1 → 1.5, 1.5 → 1.0, 2.2 → 0.3, 3 → 0.5, 3.8 → 1.3, 4.5 → 2.0.

    • \(K = 1\): the nearest machine is at 2.2 (distance 0.3), which is faulty, so predict faulty.
    • \(K = 3\): the three nearest are at 2.2, 3, 1.5: faulty, healthy, healthy. The majority is healthy.

    The prediction can change with \(K\): that is why \(K\) is chosen by checking the error on new data.

    Summary of Lecture 1#

    • Machine learning learns rules (a model) from data with known answers.
    • Every method has three parts: representation, evaluation, optimisation.
    • We assume \(Y = f(X) + \varepsilon\) and estimate \(f\); the noise \(\varepsilon\) cannot be removed.
    • Judge a model by its test error. Too simple underfits (high bias); too flexible overfits (high variance).
    • Classification uses the error rate; KNN estimates class probabilities from the \(K\) nearest neighbours.
