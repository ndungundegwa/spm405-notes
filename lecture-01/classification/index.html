    Classification#

    Classification: the error rate#

    For categories the MSE makes no sense. Count the mistakes instead

    “Faulty minus healthy” has no meaning, so we cannot square a difference.

    Error rate (fraction of wrong labels): \(\frac1n\sum_{i=1}^n I(y_i \neq \hat y_i)\)

    \(I(\cdot)\) is the indicator function: 1 if the statement in brackets is true, 0 if false. For each observation it gives 1 for a wrong label, 0 for a right one; adding them counts the mistakes, and dividing by \(n\) gives the fraction.

    As with the MSE, we care about the test error rate

    The error on new data is what matters.

    Example: 10 motors; the model labels 2 of them wrongly. Error rate \(= 2/10 = 0.2\). Accuracy \(= 1 - 0.2 = 0.8\)

    The accuracy (fraction correct) of slide 18 is one minus the error rate.

    Symbols

    \(\hat y_i\)Predicted class of observation \(i\).
    \(\neq\)Is not equal to.
    \(I(\cdot)\)Indicator: 1 if the statement is true, 0 if false.

    The Bayes classifier#

    Assign the input \(x_0\) to the class \(j\) with the largest \(\Pr(Y = j \mid X = x_0)\)

    For each input, pick the class that is most probable for that input. The vertical bar is read “given”.

    It has the lowest possible error rate (the Bayes error rate)

    No classifier can do better, because it always picks the most probable class.

    But we never know these probabilities in practice: it is an ideal, not a method

    The true probabilities are unknown, so it is an ideal to approach. In the notebook the data are simulated, so the Bayes classifier is known and we can compare against it.

    Example: a motor vibrates at 6 mm/s. Suppose \(\Pr(\text{faulty} \mid 6\text{ mm/s}) = 0.8\) and \(\Pr(\text{healthy} \mid 6\text{ mm/s}) = 0.2\). The Bayes classifier says faulty

    Of all motors that vibrate at 6 mm/s, 80% are faulty. Labelling them all faulty is wrong 20% of the time, and no rule can do better at that vibration level.

    The Bayes error rate plays the role of the irreducible error: no classifier can beat it

    The classification version of \(\operatorname{Var}(\varepsilon)\) on slide 26.

    Symbols

    \(j\)A class label.
    \(\Pr(Y = j \mid X = x_0)\)Probability that the class is \(j\), given input \(x_0\).

    \(K\)-nearest neighbours (KNN)#

    Find the \(K\) training points closest to \(x_0\), then estimate \(\Pr(Y = j \mid X = x_0) \approx \frac1K\sum_{i\in\mathcal N_0} I(y_i = j)\) and choose the most common class

    KNN estimates the unknown probabilities from the neighbours: the probability of class \(j\) is the fraction of the \(K\) nearest training points that belong to class \(j\). Then it picks the most common class.

    Small \(K\) (1 or 3): flexible, noisy boundary \(\Rightarrow\) may overfit

    With \(K = 1\), each new point takes the label of its single nearest neighbour; the boundary follows every noisy point. The training error is zero, but the test error is not.

    Large \(K\): smooth boundary \(\Rightarrow\) may underfit

    With a very large \(K\), the vote is taken over a wide region and the boundary becomes too smooth to follow the real shape. \(K\) plays the same role as the polynomial degree on slide 34, in reverse: small \(K\) is flexible.

    Example: \(K = 5\): 4 of the 5 nearest motors are faulty, so \(\Pr(\text{faulty}) \approx 4/5 = 0.8\): label faulty

    The indicator is 1 for the four faulty neighbours and 0 for the healthy one; the sum is 4 and \(\frac1K = \frac15\).

    KNN is non-parametric: it keeps the training data and assumes no formula for \(f\)

    As on slide 28.

    \(K\)Number of neighbours used by KNN.
    \(\mathcal N_0\)The set of the \(K\) training points nearest to \(x_0\).

    Example: KNN by hand#

    Six machines have vibration levels (mm/s) and known states:

    vibration1.01.52.23.03.84.5
    statehealthyhealthyfaultyhealthyfaultyfaulty

    Classify a new machine with vibration 2.5 mm/s using KNN with \(K = 1\) and with \(K = 3\).

    Solution triple-click to reveal

    Distances from 2.5: 1 → 1.5, 1.5 → 1.0, 2.2 → 0.3, 3 → 0.5, 3.8 → 1.3, 4.5 → 2.0.

    • \(K = 1\): the nearest machine is at 2.2 (distance 0.3), which is faulty, so predict faulty.
    • \(K = 3\): the three nearest are at 2.2, 3, 1.5: faulty, healthy, healthy. The majority is healthy.

    The prediction can change with \(K\): that is why \(K\) is chosen by checking the error on new data.

    Summary#

    Machine learning learns rules (a model) from data with known answers

    Every method has three parts: representation, evaluation, optimisation

    We assume \(Y = f(X) + \varepsilon\) and estimate \(f\); the noise \(\varepsilon\) cannot be removed

    Judge a model by its test error. Too simple underfits (high bias); too flexible overfits (high variance)

    Classification uses the error rate; KNN estimates class probabilities from the \(K\) nearest neighbours

    These five points are what students should take from the lecture; each returns in every later lecture.
