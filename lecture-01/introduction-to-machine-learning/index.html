    What is machine learning?#

    This page answers three questions: what machine learning is, why we need it, and how every machine-learning method can be described by the same three ingredients. It ends with the vocabulary used throughout the course and the main types of machine learning.

    Notation on this page

    SymbolMeaning
    \(T\)the task a program must perform
    \(P\)the performance measure: the number that scores how well the task is done
    \(E\)the experience: the data the program learns from

    A definition#

    Artificial intelligence (AI) is the broad goal of making computers perform tasks that seem to require intelligence. Machine learning (ML) is the part of AI in which the computer learns how to do a task from examples, instead of following rules written for it by a person. In short, machine learning lets computers learn from data without being explicitly programmed.

    The economist and AI pioneer Herbert Simon put the idea of learning in one sentence: “Learning is any process by which a system improves performance from experience.” The definition applies to people and machines alike.

    Tom Mitchell (1997) made it precise. A computer program is said to learn from experience \(E\) with respect to a task \(T\) and a performance measure \(P\) if its performance on \(T\), as measured by \(P\), improves with experience \(E\). To claim that a program learns you must therefore name three things:

    • the task \(T\): what the program has to do;
    • the performance measure \(P\): how its success is scored;
    • the experience \(E\): what it learns from, usually a collection of data.

    Learning then means that \(P\) gets better as \(E\) grows.

    Example: detecting faulty motors. A worn bearing or a loose mounting changes the way an electric motor vibrates, and an accelerometer attached to the motor records that vibration.

    • \(T\): label each motor as healthy or faulty from its vibration signal.
    • \(P\): the fraction of motors labelled correctly.
    • \(E\): past vibration records for which a technician later confirmed whether the motor was healthy or faulty.

    Why machine learning?#

    The rules that machine learning produces are called a model: a rule that turns inputs into answers. Once it has been learned, a model is used just like a traditional program: give it new data and it returns answers. There are three common reasons to learn the rules instead of writing them by hand.

    1. The rules are too hard to write. An experienced technician can hear a failing bearing, but nobody can write down precise rules that separate worn from healthy bearings in terms of thousands of signal samples. Learning from many labelled signals works far better.
    2. There is too much data. A factory with 500 sensors, each read 100 times per second, produces \(500 \times 100 \times 86\,400 \approx 4.3\) billion readings per day (there are 86 400 seconds in a day). Only an automatic method can watch them all.
    3. Systems change. Detectors age and sensors drift. Hand-written rules must then be rewritten; a learned model is simply retrained on new data.

    The three ingredients of every method#

    Every machine-learning method can be described by three choices. We use this framework in every lecture.

    Representation: how do raw measurements become numbers? A computer model works with numbers, so each object we study must be described by a list of numbers. A vibration signal can be described by its amplitudes at 1000 frequencies (its Fourier spectrum); a camera image by its pixel values; a smart meter's record by 24 numbers per day, the energy used in each hour. Representation also covers the family of models we allow, for example “all straight lines”.

    Evaluation: how do we know a model is good? We need a number that scores a model. For a numerical output we use the average squared error, called the mean squared error (see Assessing model accuracy). For a category we use the fraction labelled correctly, the accuracy. The crucial rule, which returns throughout the course: score the model on data it has not seen, never on the data used to build it.

    Optimisation: how do we find the best model? A parameter is a number inside a model that is learned from the data, for example the slope of a straight line. Optimisation searches for the parameter values with the best score. Gradient descent (Lecture 2) changes the parameters step by step in the direction that reduces the error; regularisation (Lecture 4) adds a penalty for complexity so that the model does not fit the noise.

    Words used throughout the course#

    Different books use different words for the same thing. The table gives the words used in these notes, their common alternatives, and an example from a solar panel whose power we want to predict from the sunlight falling on it and its temperature.

    WordMeaningExample (solar panel)
    observationone measured example (also: data point, reading, sample)one reading of the panel
    inputa quantity we measure and use to predict (also: variable, feature, predictor, independent variable)sunlight, cell temperature

    A few remarks:

    • An observation is one row of the data table; the inputs and the output are its columns.
    • “Labelled data” means data whose outputs are known. The word label is used mostly for categories (“healthy”, “faulty”), but it applies to numbers too.
    • To fit or train a model means the same thing: choose its parameters from data.
    • The test data are not used in fitting, so they show how the model performs on data it has never seen.

    Types of machine learning#

    TypeWhat it learns fromExample
    Supervisedlabelled data: inputs with their known outputspredict a building's electricity use (kWh) from the outdoor temperature and the time of day
    Unsupervisedunlabelled data: inputs only; it looks for groups or structuregroup smart-meter customers by the shape of their daily load profile, with no groups given in advance
    Reinforcementtrial and error: actions earn rewards from an environmentlearn when to switch a heater on and off to hold a room at a set temperature

    Supervised learning learns from examples whose correct answers are known. Past meter readings give the correct energy use for many hours with known temperature and time; a model trained on them predicts the use for new hours.

    Unsupervised learning is given no correct answers and finds patterns by itself. Given each customer's 24 hourly readings, it can group together customers with similar daily patterns (households, shops, night-time businesses).

    Reinforcement learning has an agent that acts, receives a reward or a penalty, and learns which actions lead to good outcomes. A reward is a score the environment returns after each action; it plays the role that the label plays in supervised learning. A heater controller is rewarded when the room is close to the set temperature and penalised for the energy used, and so learns a good switching policy.

    This course covers supervised and unsupervised learning. Reinforcement learning is mentioned only for completeness.
