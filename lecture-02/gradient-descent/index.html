    Gradient descent#

    Loss and cost: what is the difference?#

    Two words that students will meet in every later lecture and in every software library, often used loosely. Fix them now.

    Loss: how wrong the model is on one data point. \(\ell_i = \frac12(y_i - \hat y_i)^2\)

    The loss is a number for a single reading: half its squared residual.

    Cost: the average loss over all \(n\) points. One number for the whole dataset. \(J(\bb) = \frac1n\sum_i\ell_i = \frac{1}{2n}\sum_i (y_i - \hat y_i)^2\)

    The cost scores a whole set of coefficients. Dividing by \(n\) keeps the numbers of a similar size whatever the data size; the \(\frac12\) cancels the 2 that appears when we differentiate.

    Training = finding the \(\bb\) with the smallest cost

    This sentence is true for every model in the course: only the form of the loss changes (cross-entropy in Lecture 3, for example).

    Cost \(= \mathrm{RSS}/2n\), so the best line is the same. Many books say “loss” for both

    Dividing by a fixed number does not move the minimum. ISLP and PyTorch use “loss” for both meanings; in this course loss is for one point and cost for the average.

    Example: 3 points with residuals \(1, -2, 3\): losses \(0.5, 2, 4.5\); cost \(J = (0.5 + 2 + 4.5)/3 = 2.33\)

    Worked numbers

    Losses: \(\frac12 \times 1^2 = 0.5\), \(\frac12 \times (-2)^2 = 2\), \(\frac12 \times 3^2 = 4.5\). RSS \(= 1 + 4 + 9 = 14\), and \(\mathrm{RSS}/2n = 14/6 = 2.33\), the same number.

    Gradient descent: walk downhill#

    Start with any \(\bb\). Repeat: \(\bb_{\text{new}} = \bb_{\text{old}} - \alpha\,\nabla J\). Stop when the cost \(J\) no longer falls

    The gradient \(\nabla J\) points uphill; a step against it goes downhill. \(\alpha\) sets the size of the step. The cost is the one of the previous slide.

    \(\alpha\) is our first example of a setting that is chosen rather than fitted (a hyperparameter, Lecture 4).

    Why learn this? Most later models (logistic regression, neural networks) have no formula. Gradient descent works for all of them

    For linear regression the normal equations already give the answer. We learn gradient descent here because the answer is known, so we can see it work.

    Plot: a bowl-shaped cost; big steps where it is steep, small steps near the bottom

    The step is \(\alpha\) times the slope, so the steps shrink automatically as the slope flattens near the minimum.

    Symbols

    \(J(\bb)\)Cost of the coefficients \(\bb\).
    \(\alpha\)Step size (learning rate).
    \(\nabla J\)Gradient: the vector of partial derivatives \(\partial J/\partial\beta_j\).

    What is the gradient \(\nabla J\)?#

    One coefficient: \(\nabla J\) is the ordinary derivative \(dJ/d\beta\). Slope negative: the cost falls to the right, so increase \(\beta\). Slope positive: decrease \(\beta\). The minus sign in the update does this

    Draw a parabola at the board, mark a point to the left of the minimum, and show that the slope there is negative, so \(-\alpha \times\) slope is a step to the right, towards the minimum.

    Many coefficients: a list of slopes, one per coefficient: \(\nabla J = (\partial J/\partial\beta_0, \partial J/\partial\beta_1, \dots, \partial J/\partial\beta_p)\)

    Each partial derivative is the slope when only that coefficient changes and the others are held fixed. Together they point in the steepest uphill direction.

    The plot on the last slide: \(J = (\beta - 2)^2\), \(\alpha = 0.2\). Slope \(dJ/d\beta = 2(\beta - 2)\); at \(\beta = 0\) it is \(-4\). \(\beta_{\text{new}} = 0 - 0.2 \times (-4) = 0.8\). Next: \(0.8 + 0.2 \times 2.4 = 1.28\), … \(\to 2\)

    These are exactly the red points of the previous slide.

    Worked numbers

    At \(\beta = 0.8\): slope \(2(0.8 - 2) = -2.4\), so \(\beta = 0.8 + 0.2 \times 2.4 = 1.28\). At 1.28: slope \(-1.44\), \(\beta = 1.568\). Each step removes 40% of the remaining distance to 2, because \(\beta - 2\) is multiplied by \(1 - 2\alpha = 0.6\).

    Gradient descent for linear regression#

    Batch (all data points in each step): \(\bb \leftarrow \bb + \frac{\alpha}{n}\bX\T(\by - \bX\bb)\)

    For the cost of slide 25, \(\nabla J = -\frac1n\bX\T(\by - \bX\bb)\). Substituting gives this update. \(\by - \bX\bb\) is the column of residuals.

    Stochastic (one point \(i\) in each step): \(\bb \leftarrow \bb + \alpha(y_i - \hat y_i)x_i\)

    Use one data point at a time, cycling through the data. Each step is cheap; used for very large datasets and for neural networks.

    As in a program: compute the right-hand side, then store it in \(\bb\).

    Read the update: the step is proportional to the error \(y_i - \hat y_i\). Big mistake: big correction. Small mistake: small correction

    When a prediction is too low, the coefficients move so as to raise it, in proportion to the input values.

    Good news: the cost is a single bowl. Downhill always leads to the one best answer

    \(J\) is a quadratic function of \(\bb\) (a convex bowl), so there is only one minimum. Neural networks do not have this property.

    Symbols

    \(\leftarrow\)Assignment: replace the old value.
    \(x_i\)Row \(i\) of \(\bX\) (with the 1 for the intercept).

    Example: one step of gradient descent by hand#

    Fit \(y = \beta x\) (no intercept) to the points \((1, 2.2), (2, 3.9), (3, 6.1)\) with cost \(J(\beta) = \frac{1}{n}\sum_i (y_i - \beta x_i)^2\). Start at \(\beta = 1\) with step size \(\alpha = 0.05\). Do one gradient-descent step. What is the exact minimiser?

    Solution triple-click to reveal
    \[ \frac{dJ}{d\beta} = -\frac{2}{n}\sum_i x_i (y_i - \beta x_i) = -\frac{2}{3}\big[1(1.2) + 2(1.9) + 3(3.1)\big] = -9.533 \]

    Update: \(\beta \leftarrow 1 - 0.05 \times (-9.533) = 1.4767\).

    Exact minimiser (set the derivative to zero): \(\beta = \sum x_i y_i / \sum x_i^2 = 28.3/14 = 2.0214\). One step moved from 1 to 1.4767, towards 2.0214.

    Choosing the step size \(\alpha\)#

    Plot: cost against step for \(\alpha = 0.01\), 0.5 and 2.1. Calibration data (temperature standardised), 40 steps

    Gradient descent on the sensor data of slide 10, starting from \(\bb = 0\) (cost \(1.49 \times 10^5\) mV\(^2\)). The vertical axis is logarithmic.

    Too small (grey): very slow

    With \(\alpha = 0.01\) the cost has only fallen to \(6.7 \times 10^4\) mV\(^2\) after 40 steps.

    About right (green): done in about 10 steps

    With \(\alpha = 0.5\) the cost reaches its minimum, 114 mV\(^2\), by step 10, and the coefficients equal the least-squares values (\(9.832\) mV/\(^\circ\)C and \(2.54\) mV).

    Too large (red): overshoots and blows up

    With \(\alpha = 2.1\) each step jumps past the minimum to a higher point on the other side; the cost grows without limit.

    Always: plot the cost at every step. It must go down

    The simplest check that the code and the step size are right.

    Worked numbers

    Minimum cost \(= \mathrm{RSS}/(2n) = 4562/40 = 114\) mV\(^2\). Cost at steps 0, 1, 2, 3 with \(\alpha = 0.5\): 149 435; 37 444; 9 447; 2 447 mV\(^2\) — about four times smaller each step. With standardised input, \(\bX\T\bX/n\) is the identity, so \(\alpha = 1\) would reach the minimum in one step, and any \(\alpha > 2\) diverges.

    Scale the inputs first#

    Raw temperatures (6 to 93 \(^\circ\)C): only tiny steps are possible; after 5000 steps, the offset is still wrong (1.4 instead of 2.5 mV)

    With raw inputs, the cost bowl is a long narrow valley: very steep across the slope direction (temperatures are large numbers) and very flat along the intercept direction. A step size small enough not to blow up across the valley (at most \(6.5 \times 10^{-4}\)) is far too small to move along it.

    Standardise each input: \(z = (x - \bar x)/s\). Every input now has mean 0 and spread 1; about 10 steps are enough

    Subtract the mean and divide by the standard deviation. All directions of the bowl become equally steep.

    Rule: standardise before gradient descent. Use the mean and \(s\) of the training data only

    Test data must be scaled with the training mean and \(s\), so that no information about the test data leaks into training.

    Sensor data: inputs often differ by many orders of magnitude (W/m\(^2\), \(^\circ\)C, mV, kHz). Scaling is a routine first step

    In the solar data, \(G\) is in hundreds and \(T\) in tens; in a vibration dataset, frequencies may be in kHz.

    Symbols

    \(z\)Standardised input.
    \(s\)Standard deviation of the input (28.1 \(^\circ\)C for the calibration temperatures).

    Worked numbers

    After fitting on \(z\), convert back: slope per \(^\circ\)C \(= \beta_z/s = 276.03/28.075 = 9.832\) mV/\(^\circ\)C; offset \(= \beta_{0z} - 9.832 \times 47.71 = 471.64 - 469.10 = 2.54\) mV.

    Things to check#

    ProblemSignFix
    Curved relationresiduals form a curveadd \(x^2\), or transform
    Noise growsresiduals fan outtransform \(y\); weighted fit
    Outlierone very large residualcheck it; do not just delete it
    Correlated inputslarge SE, strange signsdrop or combine inputs

    Curved relation: residuals form a curve; fix: add \(x^2\), or transform

    Plot the residuals against the fitted values or each input. A U-shape means the straight line misses a curve.

    Noise grows: residuals fan out; fix: transform \(y\); weighted fit

    Unequal noise (heteroscedasticity) makes the SEs wrong.

    Outlier: one very large residual; fix: check it; do not just delete it

    It may be a recording error, or the most interesting point in the dataset (a sensor starting to fail).

    Correlated inputs: large SE, strange signs; fix: drop or combine inputs

    Collinearity (ISLP 3.3.3): when inputs move together, the data cannot separate their effects, as on slide 20.

    Always plot the residuals. \(R^2\) and \(p\)-values alone can hide all of these problems

    The notebook's residual plot for the solar panel shows the dusty panels below zero: the missing input shows up in the residuals.

    Summary#

    1. Least squares chooses the line with the smallest RSS
    1. SE, \(t\) and \(p\) say how much to trust each coefficient; RSE and \(R^2\) say how well the model fits
    1. Many inputs: \(\bX\T\bX\,\hat\bb = \bX\T\by\). Each coefficient holds the other inputs fixed
    1. Categories enter as dummy variables; products of inputs give interactions
    1. Gradient descent finds the same answer step by step; standardise first and watch the cost

    Ask students to state each point in their own words before showing it.
