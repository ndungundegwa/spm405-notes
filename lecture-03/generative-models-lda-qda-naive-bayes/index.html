    Generative models: LDA, QDA, naive Bayes#

    Logistic regression models the probability of each class directly. This page takes another route: describe what each class looks like, then use Bayes' theorem to work out which class a new observation most probably belongs to. It covers linear and quadratic discriminant analysis and naive Bayes, compares all the classifiers met so far on the same test data, and extends classification to more than two classes.

    Probability words#

    The methods on this page are described in the language of probability.

    • Conditional probability \(\Pr(A \mid B)\): the probability of \(A\) given that \(B\) is true. For example \(\Pr(\text{faulty} \mid v = 6\ \text{mm/s})\) is, among machines vibrating at 6 mm/s, the fraction that are faulty.
    • Prior \(\pi_k\): the probability of class \(k\) before we look at the inputs, i.e. how common the class is. If 30% of machines in a plant are faulty, the prior for “faulty” is 0.3.
    • Density \(f_k(x)\): how the inputs are spread in class \(k\); it is high where class-\(k\) points are common. For one input, think of a smoothed histogram of the readings from that class.
    • Normal (Gaussian) distribution: the bell-shaped distribution, fixed by its mean \(\mu\) (Greek “mu”), the centre, and its spread.
    • Covariance \(\Sigma\): with several inputs, the spread of each input and how the inputs vary together. With two inputs it is a \(2 \times 2\) table, with the two variances on the diagonal and the covariance (which sets the correlation) off it. It fixes the size, shape and tilt of the elliptical cloud of points. Beware: the same Greek letter \(\Sigma\) also means “sum”; the context tells which.

    Another route: model each class#

    Logistic regression models \(\Pr(Y = k \mid X)\) directly. It is a discriminative method: it describes only the boundary between the classes.

    A generative method instead describes each class fully: what healthy machines look like, what faulty ones look like, and how common each is. Bayes' theorem then turns this into the probability of each class for a given input \(x\):

    \[ \Pr(Y = k \mid X = x) = \frac{\pi_k\, f_k(x)}{\sum_l \pi_l\, f_l(x)} . \]

    The numerator is “how common class \(k\) is” times “how typical \(x\) is of class \(k\)”; the denominator, a sum over all classes \(l\), makes the probabilities add up to 1. We then predict the class with the largest probability. This is exactly the Bayes classifier of Lecture 1, with its ingredients now estimated from data:

    • the prior \(\pi_k\) is estimated by the fraction of class \(k\) in the training data;
    • the density \(f_k(x)\) is estimated by a model of how \(X\) is distributed in class \(k\).

    The methods below differ only in how they model \(f_k\).

    Machines. Of the 400 training machines, 122 are faulty, so \(\hat\pi_{\text{faulty}} = 122/400 = 0.305\) and \(\hat\pi_{\text{healthy}} = 0.695\). Before looking at the sensors, a machine is faulty with probability 0.305.

    Worked numbers: Bayes' theorem for one machine

    Suppose for some reading \(x\) the densities are \(f_{\text{faulty}}(x) = 0.02\) and \(f_{\text{healthy}}(x) = 0.01\) (made-up numbers). Then \(\Pr(\text{faulty} \mid x) = 0.305 \times 0.02/(0.305 \times 0.02 + 0.695 \times 0.01) = 0.0061/0.01305 = 0.47\). Although the reading is twice as typical of faulty machines, the prior tips the decision to healthy.

    Linear discriminant analysis (LDA)#

    LDA assumes that each class is a normal (Gaussian) cloud of points, with

    • its own mean \(\mu_k\) (the clouds may sit in different places), but
    • the same covariance \(\Sigma\) for all classes (the clouds have the same size, shape and tilt).

    With equal covariances, the quadratic terms in \(x\) cancel when the two class densities are compared, and the boundary between the classes is a straight line (ESL Section 4.3).

    Machines. The estimated class means are: healthy, \(v = 2.5\) mm/s and \(T = 50.0\) \(^\circ\)C; faulty, \(v = 4.7\) mm/s and \(T = 60.8\) \(^\circ\)C. (The true values in the simulation are 2.5, 50 and 4.5, 60.)

    LDA or logistic regression? Both give a straight-line boundary. LDA is more stable when the classes are well separated or the data are few: when a line separates the classes perfectly, the logistic coefficients grow without limit, but LDA's do not. When the Gaussian assumption is badly wrong, logistic regression is the safer choice.

    Quadratic discriminant analysis (QDA)#

    QDA lets each class have its own covariance \(\Sigma_k\), so the clouds may have different sizes and tilts. The boundary then becomes a curve (a quadratic one, hence the name).

    The price is more parameters to estimate, so QDA needs more data. With two inputs each covariance has three numbers (two spreads and a correlation); QDA estimates one set per class, LDA one set in total. With \(p\) inputs a covariance has \(p(p + 1)/2\) numbers, so with many inputs the difference is large.

    In our machines, faulty machines vary much more than healthy ones: about twice the spread, with a strong correlation between vibration and temperature, while healthy ones have neither. QDA suits this.

    Naive Bayes#

    Naive Bayes assumes that the inputs are independent within each class (knowing one input tells us nothing about another), so the class density is a product of one-dimensional densities:

    \[ f_k(x) = f_{k1}(x_1) \times f_{k2}(x_2) \times \dots \times f_{kp}(x_p), \]

    where \(f_{kj}(x_j)\) describes how input \(j\) alone is spread in class \(k\). Instead of a joint distribution for all inputs we estimate one simple distribution per input per class, and multiply.

    Only one-dimensional distributions are needed, so naive Bayes works with many inputs and little data. The independence assumption is usually false, and the method is “naive” because it ignores, for instance, that in faulty machines vibration and temperature rise together (their correlation of 0.8 is thrown away). Yet it often still classifies well: its probabilities may be poor, but the ranking of the classes is often right, which is all a classifier needs. It shines in problems like spam filtering, with thousands of inputs (words), each simple on its own.

    Comparing classifiers on the test machines#

    All the classifiers met so far, fitted on the same 400 training machines and scored on the same 2000 test machines. The test error is \(1 -\) accuracy; KNN uses standardised inputs.

    LDA0.1180.889
    QDA0.1100.906
    Naive Bayes0.1160.885
    KNN, \(K = 1\)0.1700.797
    KNN, \(K = 15\)0.1120.885
    • The first row is the baseline: 593 of the 2000 machines are faulty, so always saying “healthy” is wrong \(593/2000 = 29.6\%\) of the time. Any useful method must beat it.
    • All the good methods reach about 11% error. The overlap of the classes sets a floor that no method can beat.
    • QDA is best, because the classes really have different shapes: its assumption matches how the data were made.
    • KNN with \(K = 1\) overfits: training error 0 (each training machine is its own nearest neighbour), test error 0.17.
    • No method wins everywhere. On another data set the order may be reversed. Always compare methods on the same test data.

    More than two classes#

    To decide the type of fault (imbalance, misalignment or bearing wear) we need \(K = 3\) classes. Multi-class logistic regression gives each class \(k\) its own linear score,

    \[ z_k = \beta_{0k} + \beta_{1k}X_1 + \beta_{2k}X_2 + \dots , \]

    and the softmax function turns the \(K\) scores into probabilities:

    \[ \Pr(Y = k \mid X) = \frac{e^{z_k}}{e^{z_1} + e^{z_2} + \dots + e^{z_K}} . \]

    The exponentials make every number positive; dividing by their sum makes them add up to 1. We predict the class with the largest probability. With \(K = 2\), softmax reduces to the sigmoid.

    Example. Scores \(z = (2, 1, 0)\) give \(e^2 = 7.39\), \(e^1 = 2.72\), \(e^0 = 1\), with sum 11.11, so the probabilities are \(0.665\), \(0.245\) and \(0.090\).

    LDA, QDA, naive Bayes and KNN handle \(K\) classes directly. Softmax is also the last layer of most neural-network classifiers (Lecture 7).

    Things to watch#

    • Rare classes. If 99% of machines are healthy, “always say healthy” is 99% accurate and useless. Look at recall and precision, not only accuracy. In real plants faults are rare, so this matters.
    • Standardise for KNN. KNN's distances mix mm/s and \(^\circ\)C. Temperatures vary by about 7.6 \(^\circ\)C and vibrations by about 1.5 mm/s, so without scaling the distance is dominated by temperature. Standardising lowers the error of KNN (\(K = 15\)) from 0.120 to 0.112. Logistic regression and LDA are not affected by scaling.
    • Curved boundaries. Use QDA, or add inputs such as \(x^2\) or \(x_1x_2\) to logistic regression, as in Lecture 2.
    • Perfectly separated classes. If a line separates the classes perfectly, the likelihood keeps improving as the S-curve becomes a sharper step, so the logistic coefficients grow without limit. Regularisation (Lecture 4) fixes this.
    • Judge on test data, never on the training data.

    Summary of Lecture 3#

    1. Logistic regression: \(p = \sigma(\beta_0 + \beta_1X_1 + \dots)\); the log-odds is linear; it is fitted by maximum likelihood (minimum cross-entropy).
    2. A threshold turns a probability into a decision; its choice trades missed faults against false alarms.
    3. Judge a classifier with the confusion matrix, recall, precision and the ROC curve, on test data.
    4. LDA, QDA and naive Bayes model each class, then use Bayes' theorem.
    5. Try several methods and compare them on the same test data.
