    Generative models: LDA, QDA, naive Bayes#

    Probability words for the next four slides#

    WordMeaning
    \(\Pr(A \mid B)\)probability of \(A\) given that \(B\) is true (conditional probability)
    prior \(\pi_k\)probability of class \(k\) before we look at \(X\): how common the class is
    density \(f_k(x)\)how the inputs \(X\) are spread in class \(k\): high where class-\(k\) points are common
    normal (Gaussian)the bell-shaped distribution, set by its mean and spread
    mean \(\mu\)(“mu”) the centre of a distribution: the average
    covariance \(\Sigma\)(capital “sigma”, here not a sum) the spread of each input and how inputs vary together: it sets the size, shape and tilt of the cloud of points

    LDA, QDA and naive Bayes are described in the language of probability. Most students have met these words in a statistics course but may not be fluent. Go through them before the formulas.

    \(\Pr(A \mid B)\): probability of \(A\) given that \(B\) is true (conditional probability)

    For example, \(\Pr(\text{faulty} \mid v = 6~\text{mm/s})\): among machines vibrating at 6 mm/s, the fraction that are faulty.

    Prior \(\pi_k\): probability of class \(k\) before we look at \(X\): how common the class is

    If 30% of machines in the plant are faulty, the prior for “faulty” is 0.3.

    Density \(f_k(x)\): how the inputs \(X\) are spread in class \(k\): high where class-\(k\) points are common

    For one input, think of a smoothed histogram of the readings from that class.

    Normal (Gaussian): the bell-shaped distribution, set by its mean and spread. Mean \(\mu\) (“mu”): the centre of a distribution: the average

    Covariance \(\Sigma\) (capital “sigma”, here not a sum): the spread of each input and how inputs vary together: it sets the size, shape and tilt of the cloud of points

    With two inputs it is a \(2 \times 2\) table: the two variances on the diagonal and the covariance (which sets the correlation) off it. Warn students that the same Greek letter \(\Sigma\) also means “sum”; the context tells which.

    Bayes' theorem turns “how \(X\) looks in each class” into “which class, given \(X\)”

    The next slide gives the formula.

    Another route: model each class#

    Logistic regression models \(\Pr(Y = k \mid X)\) directly

    It is called a discriminative method: it only describes the boundary between classes.

    Instead, describe how \(X\) is spread in each class, then use Bayes' theorem: \(\Pr(Y = k \mid X = x) = \pi_kf_k(x)/\sum_l \pi_lf_l(x)\)

    A generative method describes each class fully: what healthy machines look like, what faulty ones look like, and how common each is. Bayes' theorem then turns this into the probability of each class for a given machine.

    Predict the class with the largest probability

    This is the Bayes classifier of Lecture 1, with estimated ingredients.

    Two ingredients: \(\pi_k\) (“pi”), fraction of class \(k\) in the training data; \(f_k(x)\), how \(X\) is distributed in class \(k\)

    The methods on the next slides differ only in how they estimate \(f_k\).

    Machines: \(\hat\pi_{\text{faulty}} = 122/400 = 0.305\), \(\hat\pi_{\text{healthy}} = 0.695\)

    The prior: before looking at the sensors, a machine is faulty with probability 0.305.

    Symbols

    \(k\)Class label.
    \(\pi_k\)Prior probability of class \(k\).
    \(f_k(x)\)Probability density of the inputs in class \(k\).
    \(\sum_l\)Sum over all classes.

    Worked numbers

    Bayes' theorem for one machine: if \(f_{\text{faulty}}(x) = 0.02\) and \(f_{\text{healthy}}(x) = 0.01\) (made-up densities), then \(\Pr(\text{faulty} \mid x) = 0.305 \times 0.02/(0.305 \times 0.02 + 0.695 \times 0.01) = 0.0061/0.01305 = 0.47\). Although the reading is twice as typical of faulty machines, the prior tips the decision to healthy.

    Linear discriminant analysis (LDA)#

    Assume each class is a normal (Gaussian) cloud: each class has its own mean \(\mu_k\); all classes share the same spread and shape (covariance \(\Sigma\))

    Picture each class as an elliptical cloud of points. LDA allows the clouds to sit in different places but insists they have the same size, shape and tilt.

    Then the boundary between classes is a straight line

    With equal covariances, the quadratic terms in \(x\) cancel in the ratio of the two densities, leaving a linear boundary (ESL 4.3).

    Machines: class means: healthy \(v = 2.5\) mm/s, \(T = 50.0~^\circ\)C; faulty \(v = 4.7\) mm/s, \(T = 60.8~^\circ\)C

    Estimated from the training data. (True: 2.5, 50 and 4.5, 60.)

    LDA or logistic? Both give a straight-line boundary. LDA is more stable when classes are well separated or data are few

    When classes are perfectly separated, logistic coefficients blow up (slide 33); LDA does not. When the Gaussian assumption is badly wrong, logistic regression is safer.

    Symbols

    \(\mu_k\)Mean of the inputs in class \(k\).
    \(\Sigma\)Covariance matrix: spreads and correlations of the inputs.

    QDA: each class has its own shape#

    Quadratic discriminant analysis: each class has its own covariance \(\Sigma_k\)

    The clouds may now have different sizes and tilts.

    The boundary becomes a curve. More parameters to estimate: needs more data

    With two inputs, each covariance has three numbers (two spreads and a correlation). QDA estimates one per class; LDA one in total. With many inputs the difference is large: \(p(p + 1)/2\) per class.

    Faulty machines vary much more than healthy ones, so QDA suits them

    In the simulation, faulty machines have about twice the spread and a strong correlation; healthy ones have neither.

    Plot: black, logistic boundary; red, QDA boundary

    The QDA boundary curves around the compact healthy cloud.

    Symbols

    \(\Sigma_k\)Covariance matrix of class \(k\).

    Naive Bayes#

    Assume the inputs are independent within each class: \(f_k(x) = f_{k1}(x_1) \times \dots \times f_{kp}(x_p)\)

    Instead of a joint distribution for all inputs, estimate one simple distribution per input per class, and multiply.

    Only one-dimensional distributions to estimate: works with many inputs and little data. The assumption is usually false, but the method often still works

    The probabilities it gives may be poor, but the ranking of classes is often right, which is all a classifier needs.

    Why “naive”: in faulty machines, vibration and temperature rise together. Naive Bayes ignores this

    The correlation of 0.8 in faulty machines is thrown away.

    Where it shines: spam filters and text: thousands of inputs (words), each simple on its own

    Symbols

    \(f_{kj}(x_j)\)Distribution of input \(j\) in class \(k\).

    All good methods reach about 11% error

    The overlap of the classes sets a floor that no method can beat.

    QDA is best: the classes really have different shapes

    Its assumption matches how the data were generated.

    KNN with \(K = 1\) overfits: training error 0, test error 0.17

    Each training machine is its own nearest neighbour, so training error is zero; on new machines the boundary follows noise (Lecture 1).

    No method wins everywhere. Compare on test data

    On another dataset the order may be reversed.

    More than two classes#

    With \(K\) classes, each class \(k\) gets its own line \(z_k = \beta_{0k} + \beta_{1k}X_1 + \dots\)

    Note: here \(K\) is the number of classes, not the number of neighbours as in KNN.

    Softmax turns the \(K\) numbers into probabilities: \(\Pr(Y = k \mid X) = e^{z_k}/(e^{z_1} + \dots + e^{z_K})\)

    Exponentials make every number positive; dividing by the sum makes them add up to 1. With \(K = 2\) it reduces to the sigmoid.

    All probabilities are positive and add up to 1. Predict the class with the largest

    Fault type: imbalance, misalignment or bearing wear? Three classes, three lines, one softmax

    LDA, QDA, naive Bayes and KNN handle \(K\) classes directly. Softmax is the last layer of most neural-network classifiers (Lecture 7)

    Worked numbers

    If \(z = (2, 1, 0)\): \(e^2 = 7.39\), \(e^1 = 2.72\), \(e^0 = 1\); sum 11.11. Probabilities \(0.665\), \(0.245\), \(0.090\).

    Things to watch#

    Rare classes: if 99% of machines are healthy, “always say healthy” is 99% accurate and useless. Look at recall and precision, not only accuracy

    In real plants faults are rare, so this matters.

    Standardise for KNN: distances mix mm/s and \(^\circ\)C. Standardising lowers the KNN (\(K = 15\)) error from 0.120 to 0.112

    Temperatures vary by about 7.6 \(^\circ\)C, vibrations by about 1.5 mm/s; unscaled, the distance is dominated by temperature. Logistic regression and LDA are not affected by scaling.

    Curved boundaries: use QDA, or add inputs such as \(x^2\) or \(x_1x_2\) to logistic regression

    As in Lecture 2.

    Perfectly separated classes: logistic coefficients grow without limit. Regularisation (Lecture 4) fixes this

    If a line separates the classes perfectly, the likelihood keeps improving as the S-curve becomes a sharper step.

    Judge on test data, never on the training data

    Summary#

    1. Logistic regression: \(p = \sigma(\beta_0 + \beta_1X_1 + \dots)\); the log-odds is linear; fit by maximum likelihood
    1. A threshold turns a probability into a decision; its choice trades missed faults against false alarms
    1. Judge a classifier with the confusion matrix, recall, precision and the ROC curve, on test data
    1. LDA, QDA and naive Bayes model each class, then use Bayes' theorem
    1. Try several methods and compare them on the same test data

    Ask students to state each point in their own words.
