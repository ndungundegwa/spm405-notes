    Logistic regression#

    In Lectures 1 and 2 the output was mostly a number. Now the output is a category: a machine is healthy or faulty, a milk sample pure or adulterated, a sensor reading normal or an anomaly. This page develops the most widely used classifier, logistic regression: the model, how to read its coefficients, how it is fitted by maximum likelihood, and how its probabilities become decisions.

    Classification problems#

    Typical classification problems in physics and instrumentation:

    • Is a machine healthy or faulty?
    • Is a milk sample pure or adulterated?
    • Is a sensor reading normal, or an anomaly?
    • Which fault does a machine have: imbalance, misalignment or bearing wear?

    The first three have two classes; the last has three (more than two classes are treated on the generative models page).

    With two classes we code the output as \(Y = 1\) (“yes”, usually the class we want to detect, e.g. faulty) or \(Y = 0\) (“no”, e.g. healthy). Rather than a bare yes or no, we want the probability that \(Y = 1\):

    \[ p(X) = \Pr(Y = 1 \mid X). \]

    The vertical bar is read “given”: \(\Pr(Y = 1 \mid X)\) is the probability that \(Y = 1\) for this value of \(X\). The probability changes with the inputs: a motor vibrating at 6 mm/s has a different probability of a fault from one at 2 mm/s.

    Classification therefore has two separate steps, and keeping them apart is the key idea of this lecture:

    1. Estimate the probability of each class.
    2. Turn the probability into a decision, using a threshold that depends on the costs of the possible mistakes.

    Example: vibration and motor faults#

    A motor with a worn bearing or a loose mounting vibrates more. Vibration monitoring is the standard tool of predictive maintenance: an accelerometer on the motor housing measures how strongly it shakes. The severity is usually reported as the RMS (root-mean-square) vibration velocity \(v\) in mm/s, the typical speed of the vibrating surface, which is the quantity used in the ISO vibration-severity standards.

    Our data: 200 motors, with input \(X = v\) and output \(Y = 1\) if the motor was faulty, 0 if healthy. 114 of the 200 are faulty.

    Why not use linear regression?#

    We could treat 0 and 1 as numbers and fit a least-squares line, as in Lecture 2. For the motors this gives

    \[ \hat y = -0.15 + 0.144\,v . \]

    At \(v = 0\) the line predicts \(-0.15\); at \(v = 10\) mm/s it predicts \(-0.15 + 0.144 \times 10 = 1.29\). Neither is a possible probability. A straight line also rises at the same rate everywhere, while the real probability is flat near 0, rises steeply in the grey zone, and is flat again near 1. We need a curve that stays between 0 and 1.

    The logistic (sigmoid) function#

    The logistic function, also called the sigmoid (“S-shaped”), is

    \[ \sigma(z) = \frac{1}{1 + e^{-z}} , \]

    where \(e = 2.718\ldots\) is Euler's number. Note that the Greek letter \(\sigma\) here names a function; it has nothing to do with the noise standard deviation \(\sigma\) of earlier lectures.

    Its properties:

    • Any number \(z\) can go in, and the output is always between 0 and 1. \(e^{-z}\) is always positive, so the denominator is always greater than 1 and the fraction lies between 0 and 1.
    • \(z = 0\) gives \(\sigma(0) = 1/(1 + e^0) = 1/2\).
    • Large positive \(z\) gives a value close to 1: \(\sigma(4) = 1/(1 + e^{-4}) = 1/1.018 = 0.982\).
    • Large negative \(z\) gives a value close to 0: \(\sigma(-4) = 1/(1 + 54.6) = 0.018\).

    The logistic regression model#

    Put a straight line inside the sigmoid:

    \[ p(X) = \sigma(\beta_0 + \beta_1 X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X)}} . \]

    The linear part \(\beta_0 + \beta_1 X\) is the same as in Lecture 2 and can be any number; the sigmoid squeezes it into a probability between 0 and 1.

    • If \(\beta_1 > 0\), \(p\) rises with \(X\); if \(\beta_1 < 0\), it falls.
    • The steepness of the S is set by \(\beta_1\): a large \(\beta_1\) gives a sharp step, a small one a gentle slope.
    • The position of the S is where the line crosses zero, because \(\sigma(0) = 0.5\): \(p = 0.5\) at \(X = -\beta_0/\beta_1\).

    Odds and log-odds#

    The odds are the probability of yes divided by the probability of no:

    \[ \text{odds} = \frac{p}{1 - p} . \]

    \(p = 0.5\) gives odds of 1 (“evens”); \(p = 0.8\) gives odds of \(0.8/0.2 = 4\) (“four to one”). Odds run from 0 to \(\infty\).

    For logistic regression, the logarithm of the odds, the log-odds or logit, is a straight line in \(X\):

    \[ \ln\frac{p}{1 - p} = \beta_0 + \beta_1 X . \]

    So logistic regression is linear regression for the log-odds.

    From \(p\) to the log-odds

    From \(p = 1/(1 + e^{-z})\) we get \(1 - p = e^{-z}/(1 + e^{-z})\), so \(p/(1 - p) = 1/e^{-z} = e^{z}\) and therefore \(\ln[p/(1 - p)] = z\).

    Reading \(\beta_1\). Increase \(X\) by 1 and the log-odds increase by \(\beta_1\). Adding \(\beta_1\) to a logarithm multiplies the quantity by \(e^{\beta_1}\), so the odds are multiplied by \(e^{\beta_1}\). Note that it is the odds, not the probability, that change by a fixed factor.

    Example: probability, odds and log-odds#

    A fitted model for motor faults is \(\ln\frac{p}{1-p} = -6 + 1.5\,x\), with \(x\) the vibration level (mm/s). (a) Find the probability of a fault at \(x = 5\). (b) At which vibration is the probability 50%? (c) By what factor do the odds grow for each extra 1 mm/s?

    Solution triple-click to reveal

    (a) \(z = -6 + 1.5 \times 5 = 1.5\), so \(p = 1/(1 + e^{-1.5}) = 0.818\). The odds are \(e^{1.5} = 4.48\).

    (b) \(p = 0.5\) when \(z = 0\): \(x = 6/1.5 = 4\) mm/s.

    (c) The log-odds rise by 1.5 per mm/s, so the odds are multiplied by \(e^{1.5} = 4.48\).

    What is a likelihood?#

    Before fitting logistic regression we need one new idea, shown first with a coin, where the answer is obvious.

    The likelihood \(L\) is the probability of getting the data we actually observed, if the model's parameters had a given value. The data are fixed (they have been measured); the parameter is what we vary. For each possible parameter value, the likelihood says how probable our actual data would have been.

    Maximum likelihood chooses the parameters that make the observed data most probable. It is the principle behind most fitting methods in this course.

    Example: a coin. Ten tosses give 7 heads and 3 tails. Let \(q\) be the probability of heads. Each head has probability \(q\) and each tail \(1 - q\); the tosses are independent, so the probabilities multiply:

    \[ L(q) = q^7 (1 - q)^3 . \]
    \(q\)0.50.70.9
    \(L(q)\)0.00100.00220.0005

    The likelihood is largest at \(\hat q = 0.7\), the obvious answer: the fraction of heads, 7 out of 10.

    Worked numbers

    \(0.5^7 \times 0.5^3 = 0.5^{10} = 0.000977\). \(0.7^7 \times 0.3^3 = 0.0824 \times 0.027 = 0.00222\). \(0.9^7 \times 0.1^3 = 0.478 \times 0.001 = 0.00048\).

    Why \(\hat q = 7/10\) exactly

    \(\ln L = 7\ln q + 3\ln(1 - q)\). Its derivative \(7/q - 3/(1 - q)\) is zero when \(7(1 - q) = 3q\), so \(q = 0.7\).

    Fitting logistic regression by maximum likelihood#

    For given coefficients, the model assigns each motor \(i\) a probability of being faulty, \(p_i = \sigma(\beta_0 + \beta_1 v_i)\). The probability of what actually happened to that motor is \(p_i\) if it was faulty (\(y_i = 1\)) and \(1 - p_i\) if it was healthy (\(y_i = 0\)).

    The motors are independent, so the probability of the whole data set, the likelihood, is the product over all motors:

    \[ L(\boldsymbol\beta) = \prod_{i:\,y_i = 1} p_i \ \times \prod_{i:\,y_i = 0} \bigl(1 - p_i\bigr). \]

    The symbol \(\prod\) (capital Greek pi) means “multiply together”, just as \(\sum\) means “add up”; \(\prod_{i:\,y_i = 1}\) runs over the motors that were faulty. Good coefficients give a high \(p_i\) to faulty motors and a low \(p_i\) to healthy ones, which makes \(L\) large. Maximum likelihood chooses the \(\beta\)'s that make \(L\) as large as possible, exactly as with the coin. The only difference is that the coin had one parameter, while here there are two, and each motor has its own probability \(p_i\).

    (Least squares in Lecture 2 is also maximum likelihood, when the noise is Gaussian; ESL Section 2.6.3.)

    Loss and cost: cross-entropy#

    In the loss-and-cost language of gradient descent, the loss of one motor is minus the logarithm of the probability the model gave to what really happened:

    \[ \ell_i = \begin{cases} -\ln p_i & \text{if faulty } (y_i = 1),\\ -\ln(1 - p_i) & \text{if healthy } (y_i = 0). \end{cases} \]

    The cost is the average loss, which equals \(-\frac1n \ln L\):

    \[ J(\boldsymbol\beta) = -\frac1n \sum_i \Bigl[\, y_i \ln p_i + (1 - y_i)\ln(1 - p_i) \Bigr]. \]

    Since \(y_i\) is 0 or 1, only one of the two terms is non-zero for each motor (when \(y_i = 1\), the second term has the factor \(1 - y_i = 0\), and vice versa), so this one formula covers both cases. The logarithm turns the product \(L\) into a sum, which is easier to compute and avoids numbers too small for the computer; the minus sign turns maximising into minimising; and \(\frac1n\) makes it an average. Minimising this cost is the same as maximising the likelihood. It is called the cross-entropy or log loss (the name comes from information theory), and it also trains neural-network classifiers (Lecture 7).

    Confident mistakes are punished heavily. For one faulty motor:

    model's \(p_i\)situationloss \(-\ln p_i\)
    0.99confident and right0.01
    0.5unsure\(\ln 2 = 0.69\)
    0.01confident and wrong4.6

    Example: the cost of a confident mistake#

    For one machine the model gives \(p = 0.9\) for “faulty”. Compute the cross-entropy loss \(-[y\ln p + (1-y)\ln(1-p)]\) if the machine really is faulty (\(y = 1\)) and if it is healthy (\(y = 0\)).

    Solution triple-click to reveal

    \(y = 1\): loss \(= -\ln 0.9 = 0.105\). Small: the model was confident and right.

    \(y = 0\): loss \(= -\ln(1 - 0.9) = -\ln 0.1 = 2.303\). About 22 times larger: a confident wrong answer is punished hard.

    Gradient descent for logistic regression#

    Setting the derivatives of \(J\) to zero gives equations that cannot be solved by algebra: there is no formula for the best \(\boldsymbol\beta\). So we walk downhill with gradient descent. The gradient of the cross-entropy is \(-\frac1n\mathbf X^{\mathsf T}(\mathbf y - \mathbf p)\), where \(\mathbf y\) is the column of observed outcomes and \(\mathbf p\) the column of predicted probabilities, so the update is

    \[ \boldsymbol\beta \leftarrow \boldsymbol\beta + \frac{\alpha}{n}\,\mathbf X^{\mathsf T}\bigl(\mathbf y - \mathbf p\bigr). \]

    Compare it with linear regression:

    \[ \boldsymbol\beta \leftarrow \boldsymbol\beta + \frac{\alpha}{n}\,\mathbf X^{\mathsf T}\bigl(\mathbf y - \mathbf X\boldsymbol\beta\bigr). \]

    It is the same rule: the step is proportional to (measured \(-\) predicted) \(\times\) input. Only the prediction changes, a probability instead of a straight line. For example \(y = 1\) with \(p = 0.3\) gives an error of 0.7. The similarity is not a coincidence: both rules come from maximum likelihood.

    Motors. At the start all coefficients are zero, so every \(p_i = 0.5\) and the cost is \(\ln 2 = 0.693\). After 3000 steps (standardised input, \(\alpha = 1\)) the cost is 0.140. LogisticRegression in scikit-learn gives the same answer, using a faster (Newton-type) method.

    Switching off regularisation in scikit-learn

    By default scikit-learn's LogisticRegression adds a penalty on large coefficients (regularisation, Lecture 4). Use C=np.inf to switch it off, so that the result is pure maximum likelihood, as in ISLP.

    Motors: the result#

    The maximum-likelihood fit is

    \[ \hat p(v) = \sigma(-10.1 + 2.39\,v). \]
    • 50% point: where the line inside the sigmoid is zero, \(-10.1 + 2.39\,v = 0\), so \(v = 4.2\) mm/s. (The true value in the simulation is 4.0 mm/s.)
    • Odds: each extra mm/s multiplies the odds of a fault by \(e^{2.39} = 10.9\).
    • Is the effect real? As in Lecture 2, each coefficient has a standard error (SE). Here \(\hat\beta_1 = 2.39\), SE \(= 0.45\), and the ratio, called \(z\) for logistic regression, is \(z = 2.39/0.45 = 5.3\). \(|z| > 2\), so the effect is real.
    • In maintenance terms: below 2 mm/s the chance of a fault is under 1%; above 6 mm/s it is over 98%.

    Worked numbers

    50% point: \(10.10/2.386 = 4.24\) mm/s. Odds factor: \(e^{2.386} = 10.9\). \(z = 2.386/0.452 = 5.3\).

    \(\hat p(2) = \sigma(-10.10 + 4.77) = \sigma(-5.33) = 0.005\); \(\hat p(6) = \sigma(-10.10 + 14.32) = \sigma(4.22) = 0.985\).

    Where the standard errors come from

    \(\mathrm{SE}^2\) is the diagonal of \((\mathbf X^{\mathsf T}\mathbf W\mathbf X)^{-1}\), where \(\mathbf W\) is a diagonal matrix with entries \(W_{ii} = p_i(1 - p_i)\) (ESL Section 4.4.1).

    From a probability to a decision#

    To classify, choose a threshold, the probability above which we say “faulty”. The usual choice is 0.5: predict \(Y = 1\) if \(\hat p \ge 0.5\), i.e. predict the more probable class.

    Because \(\sigma(z) \ge 0.5\) exactly when \(z \ge 0\), the condition \(\hat p \ge 0.5\) is the same as \(\beta_0 + \beta_1 X \ge 0\). The decision boundary, the set of input values where the decision changes, is therefore where \(\beta_0 + \beta_1 X = 0\). For the motors it is \(v = 4.2\) mm/s: motors above it are called faulty.

    Logistic regression gives a probability; the threshold turns it into a yes/no decision. We are free to choose the threshold, and 0.5 is not always best: the next page, How good is a classifier?, shows how to choose it.

    Two inputs: the decision boundary is a line#

    A monitoring system records two inputs for each machine: the vibration \(v\) (mm/s) and the bearing temperature \(T\) (\(^\circ\)C). A failing bearing both vibrates and heats up through friction, so using both sensors should classify better than either alone. We have 400 training machines (122 faulty) and, kept apart, 2000 test machines (593 faulty); every performance number on the next pages is measured on the test machines.

    Logistic regression with two inputs gives

    \[ \hat p = \sigma(-15.8 + 1.28\,v + 0.199\,T). \]

    The boundary \(\hat p = 0.5\) is where \(-15.8 + 1.28\,v + 0.199\,T = 0\). Solving for \(T\):

    \[ T = 79.6 - 6.41\,v , \]

    a straight line. Machines above the line are classified faulty, those below it healthy. A machine at 2 mm/s is called faulty above \(79.6 - 12.8 = 66.8\) \(^\circ\)C; at 5 mm/s, above 47.5 \(^\circ\)C. High vibration and high temperature can each push a machine over the line.

    Worked numbers

    Dividing the boundary equation by 0.1991: \(15.84/0.1991 = 79.6\); \(1.276/0.1991 = 6.41\).
