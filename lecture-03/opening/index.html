    From last week: your group datasets#

    Last week the output \(Y\) was a number. Today \(Y\) is a category: \(Y = 1\) yes (e.g. faulty), \(Y = 0\) no (e.g. healthy)

    With two classes we code the output as 0 or 1. Which class is called 1 is our choice; usually the one we want to detect.

    We want the probability that \(Y = 1\): \(p(X) = \Pr(Y = 1 \mid X)\)

    Rather than a bare yes/no answer, we estimate a probability.

    The vertical bar is new notation for many students. The probability changes with the inputs: a motor vibrating at 6 mm/s has a different probability of a fault from one at 2 mm/s.

    Group check (10 minutes): each group, one sentence on the dataset you found. How many rows? Which columns? Is your \(Y\) a number or a category?

    Last week each group was asked to find a dataset. This is a quick check that every group has one, and that they know whether their problem is regression (Lecture 2) or classification (today).

    Today's lecture leans on words from the first two lectures. Students who missed a class, or are not yet fluent with them, should not meet them again without a definition. Go through the table quickly, with one example each.

    Coefficient \(\beta\): a number the model learns from the data. Hat: \(\hat p\), \(\hat\beta\): predicted or estimated from data

    Today the coefficients sit inside a sigmoid, but they are still found from the data, and a hat still marks an estimate.

    Loss, cost \(J\): loss: error on one point; cost: average loss over all points

    Lecture 2 used the squared error. Today the loss changes to the cross-entropy (slide 13); the idea of averaging it into a cost does not.

    Gradient descent: reduce the cost step by step, \(\bb \leftarrow \bb - \alpha\nabla J\), with step size \(\alpha\)

    Logistic regression has no formula for the best coefficients, so gradient descent is now essential, not optional.

    Standard error (SE): the “\(\pm\)” of an estimate: how much it would change with new data

    Used on slide 15 for the motors.

    Training / test data: data used to fit the model / new data used only to judge it

    Every performance number today is measured on test data.

    Standardise: \(z = (x - \bar x)/s\): mean 0, spread 1

    Needed for gradient descent and for KNN.

    KNN: \(K\)-nearest neighbours: predict the most common class of the \(K\) closest training points
