    From last week: your first models#

    Each group fitted a first linear or logistic regression

    The question for today: how well will your model do on new data?

    This is what matters for a real application: a fault detector installed in a factory meets machines it never saw.

    Lecture 1: the training error is too optimistic. Lecture 3: we used a separate test set. But often we have only one dataset

    In Lectures 1–3 the data were simulated, so we could generate thousands of test points. A group project has one dataset, often small.

    Group check (10 minutes): your model and its training error; how many rows you have; could you spare some rows for testing?

    Try it: Note which groups have fewer than about 100 rows; for them cross-validation is essential.

    This lecture leans on words from Lectures 1–3. Students who missed a class should not meet them again without a definition. Go through the table quickly, with one example each.

    MSE: mean squared error, \(\mathrm{MSE} = \frac1n\sum_i (y_i - \hat y_i)^2\), the average squared prediction error

    It has the units of \(y\) squared: for the thermistor, \(^\circ\)C\(^2\). Its square root is easier to picture: an MSE of 0.25 \(^\circ\)C\(^2\) is a typical error of 0.5 \(^\circ\)C.

    Training error: the error on the data used to fit the model. Test error: the error on new data that the model has never seen. This is what we care about

    The whole of Part 1 is about estimating the test error when we have no new data.

    Overfitting: the model follows the noise: small training error, large test error

    The high-degree polynomial of Lecture 1 is the standard picture.

    Bias, variance: bias: error from a model too simple; variance: how much the fit changes with a different sample of data

    The bias–variance trade-off of Lecture 1. Regularisation (Part 2) deliberately adds a little bias to remove a lot of variance.

    Hyperparameter: a setting we choose rather than fit, e.g. the polynomial degree or the step size \(\alpha\)

    Today's hyperparameters: the degree \(d\), the number of folds \(k\) and the penalty strength \(\lambda\).

    Standardise: \(z = (x - \bar x)/s\): every input gets mean 0 and spread 1. SE: standard error, the “\(\pm\)” of an estimate

    Standardising returns in ridge and lasso; the SE returns in the bootstrap.
