    Resampling#

    The rule of Lecture 1 is to choose a model by its test error. With simulated data we could generate thousands of new test points. A real project usually has one data set, often small. This page shows how to estimate the test error from that one data set by cross-validation, and how to find the uncertainty of almost any estimate by the bootstrap. Both work by resampling: reusing the data we have in different ways.

    A hyperparameter is a setting that we choose rather than fit from the data, such as the degree of a polynomial, the \(K\) of KNN or the step size of gradient descent. Choosing hyperparameters is the main use of cross-validation.

    Example: calibrating a thermistor#

    An NTC thermistor (negative temperature coefficient) is a resistor whose resistance \(R\) falls steeply as it warms. Thermistors are cheap, sensitive temperature sensors used in appliances, cars and instruments. We have 40 readings of \(R\) (in k\(\Omega\)) against a reference thermometer, from 0 to 100 \(^\circ\)C; the resistance falls from about 33 k\(\Omega\) at 0 \(^\circ\)C to 0.7 k\(\Omega\) at 100 \(^\circ\)C.

    Physics (the “\(B\)-parameter equation”) says that \(1/T_K\) is linear in \(\ln R\):

    \[ \frac{1}{T_K} = \frac{1}{298.15} + \frac{1}{B}\ln\frac{R}{10\ \mathrm{k\Omega}}, \]

    where \(T_K\) is the temperature in kelvin and \(B = 3950\) K is a constant of the thermistor. So \(T\) is a smooth curve in \(\ln R\). We model it with a polynomial in \(x = \ln R\):

    \[ T = \beta_0 + \beta_1 x + \beta_2 x^2 + \dots + \beta_d x^d . \]

    This is still linear in the coefficients, so it is fitted by least squares (Lecture 2). Which degree \(d\)? Too low underfits; too high fits the noise. We need the test error of each degree, but have only 40 readings.

    Worked numbers

    Solving the \(B\)-equation for \(R\) at 100 \(^\circ\)C: \(R = 10\exp[3950(1/373.15 - 1/298.15)] = 10\exp(3950 \times (-0.000674)) = 10\exp(-2.662) = 0.70\) k\(\Omega\).

    The validation-set approach#

    The simplest idea is to hold back part of the data and use it as a test set:

    1. Split the data at random into two halves.
    2. Fit each candidate model on the training half.
    3. Measure its MSE on the other half, the validation set.

    The approach has two problems:

    • The answer depends on the split. With only 20 validation points the estimate is noisy: the ten splits above chose degrees 5, 3, 2, 8, 4, 3, 9, 3, 2 and 3.
    • Only half the data are used for fitting. A model fitted on 20 points is worse than one fitted on 40, so the validation error overestimates the error of the final model.

    Validation set or test set? The two words are easily confused. A validation set is used to make a choice (which degree), so it influences the final model. A test set only reports how good the final model is, and is never used to choose anything.

    Leave-one-out cross-validation (LOOCV)#

    Let each point take a turn as a one-point test set:

    1. Leave out point 1. Fit the model on the other \(n - 1\) points.
    2. Predict point 1 and record its squared error \(\mathrm{MSE}_1 = (y_1 - \hat y_{(-1)})^2\).
    3. Repeat for every point \(i = 1, \dots, n\).

    The subscript \((-i)\) means “with point \(i\) removed”, so \(\hat y_{(-i)}\) is the prediction for point \(i\) from the model fitted without it. The LOOCV estimate of the test MSE is the average:

    \[ \mathrm{CV}_{(n)} = \frac1n \sum_{i=1}^{n} \mathrm{MSE}_i . \]
    • Good: every fit uses almost all the data, and there is no randomness: LOOCV always gives the same answer.
    • Bad: it needs \(n\) fits, which is slow for big data or slow models. (For least squares there is a shortcut that needs only one fit, ISLP equation 5.2, but not for most other methods.)

    \(k\)-fold cross-validation#

    A compromise between the validation set and LOOCV:

    1. Split the data at random into \(k\) groups of about equal size, called folds.
    2. Leave out fold 1; fit on the other \(k - 1\) folds; compute the MSE on fold 1, \(\mathrm{MSE}_1\).
    3. Repeat for every fold \(j = 1, \dots, k\).

    The \(k\)-fold estimate is the average over the folds:

    \[ \mathrm{CV}_{(k)} = \frac1k \sum_{j=1}^{k} \mathrm{MSE}_j . \]

    Every point is left out exactly once. The usual choice is \(k = 5\) or \(k = 10\); with \(k = 10\) and \(n = 40\), each fit uses 36 points and each fold tests 4. LOOCV is the special case \(k = n\). (Beware a clash of letters: ISLP uses \(K\) both for folds and for the neighbours of KNN.)

    Example: the 5-fold cross-validation estimate#

    A thermistor model is fitted 5 times, each time leaving out one fold. The MSEs on the left-out folds are 0.41, 0.38, 0.52, 0.45 and 0.39 °C². What is the cross-validation estimate of the test MSE, and how many model fits did it cost? How many would LOOCV cost with \(n = 60\) readings?

    Solution triple-click to reveal
    \[ \mathrm{CV}_{(5)} = \frac{1}{5}(0.41 + 0.38 + 0.52 + 0.45 + 0.39) = 0.430\ ^\circ\mathrm{C}^2. \]

    It cost 5 fits. LOOCV leaves out one reading at a time: 60 fits (for least squares there is a shortcut formula, but not for most methods).

    Thermistor: cross-validation picks the degree#

    Because the thermistor data are simulated, we can also compute the true test error on 5000 new readings, and check how well cross-validation estimated it.

    • The training MSE keeps falling, from 6.64 at degree 1 to 0.17 at degree 8: more flexibility always fits the training data better. (At degree 10 even the training MSE rises, to 0.93: \(x^{10}\) is so large that rounding errors spoil the least-squares solution.)
    • LOOCV and 10-fold CV both pick \(d = 3\), with estimated MSE 0.254 and 0.253.
    • The true test MSE is also lowest at \(d = 3\) (0.34). Cross-validation chose correctly. Its level differs a little (0.25 against 0.34) because 40 points give a noisy estimate, but the shape and the minimum agree.

    Cross-validation found the right model without a separate test set.

    Worked numbers: the irreducible error

    The reference thermometer's noise is 0.5 \(^\circ\)C, variance 0.25. The 1% noise on \(R\) adds about \((0.01 \times |dT/d\ln R|)^2\), with \(|dT/d\ln R| = T_K^2/B = 323^2/3950 = 26\) K at 50 \(^\circ\)C, i.e. \((0.26)^2 = 0.07\). The total, about 0.32, is close to the best test MSE of 0.34.

    Which \(k\)? And a warning#

    LOOCV or 10-fold? LOOCV has less bias (each fit uses \(n - 1\) points) but more variance: its \(n\) fits are almost identical, so their errors are highly correlated and do not average out. 10-fold CV needs 10 fits instead of \(n\) and is usually just as good; it is the standard choice (ISLP Section 5.1.4).

    Classification: use the error rate in each fold instead of the MSE.

    Do every step inside the folds. Every step that looks at the output \(Y\), such as choosing inputs, scaling or tuning, must be repeated inside each fold, using only that fold's training part. Otherwise the CV error is far too optimistic. The classic mistake (ESL Section 7.10.2): with 5000 random inputs and 50 samples, pick the 100 inputs most correlated with \(Y\), then cross-validate. CV reports near-zero error on pure noise, because the left-out folds had already been used to choose the inputs. In scikit-learn, a Pipeline keeps every step inside the folds.

    The bootstrap#

    How uncertain is a number that has no standard-error formula? Lecture 2 gave formulas for regression coefficients, but for most other quantities there is none. Ideally we would collect 1000 new data sets and see how much the number varies. We cannot, but we can imitate new data sets by resampling the one we have. This is the bootstrap:

    1. Draw \(n\) rows with replacement from the \(n\) rows of the data. This is one bootstrap sample.
    2. Compute the number again from that sample.
    3. Repeat \(B\) times (typically \(B = 1000\)).
    4. The standard deviation of the \(B\) values is the standard error.

    “With replacement” means a drawn row is put back before the next draw, so some rows appear twice or more and some not at all. Each bootstrap sample is a plausible “other data set”.

    Worked numbers

    The probability that a given row is never drawn in \(n\) draws is \((1 - 1/n)^n\); for \(n = 200\) this is \(0.995^{200} = 0.367 \approx e^{-1}\). So about \(0.367 \times 200 \approx 73\) of 200 rows are missing from each bootstrap sample, and 63% are present.

    Example: how many readings does a bootstrap sample miss?#

    A bootstrap sample draws \(n\) readings with replacement from \(n\). What is the probability that one given reading is never drawn, for \(n = 10\) and for \(n = 1000\)?

    Solution triple-click to reveal

    One draw misses it with probability \(1 - 1/n\); \(n\) independent draws all miss it with probability \((1 - 1/n)^n\).

    • \(n = 10\): \(0.9^{10} = 0.349\)
    • \(n = 1000\): \(0.999^{1000} = 0.368\), close to \(e^{-1} = 0.368\).

    So each bootstrap sample leaves out about a third of the readings (these are the “out-of-bag” readings used in Lecture 5).

    Bootstrap example: the 50% vibration point#

    In Lecture 3 logistic regression gave the probability of a motor fault as \(\hat p(v) = \sigma(\hat\beta_0 + \hat\beta_1 v)\). The vibration at which this probability is 50% is

    \[ v_{50} = -\frac{\hat\beta_0}{\hat\beta_1} . \]

    It is a ratio of two estimates whose errors are correlated, so there is no simple standard-error formula. The bootstrap gives one: resample the 200 motors 1000 times, refit the logistic regression each time, and compute \(v_{50}\) each time.

    • Result: estimate 4.24 mm/s, bootstrap SE 0.14 mm/s, so \(v_{50} = 4.24 \pm 0.14\) mm/s.
    • 95% interval: the 2.5% and 97.5% points of the 1000 values give \([3.96, 4.51]\), close to \(4.24 \pm 2 \times 0.14 = [3.96, 4.52]\). The true value, 4.0, lies inside.

    The same recipe works for almost any number computed from data: a median, a correlation, an AUC, a time constant.
