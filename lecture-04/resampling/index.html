    Resampling#

    Example: calibrating a thermistor#

    An NTC thermistor (negative temperature coefficient) is a resistor whose resistance \(R\) falls steeply as it warms

    NTC means negative temperature coefficient. Thermistors are cheap, sensitive temperature sensors used in appliances, cars and instruments.

    Data: 40 readings of \(R\) (k\(\Omega\)) against a reference thermometer, 0 to 100 \(^\circ\)C

    The resistance falls from about 33 k\(\Omega\) at 0 \(^\circ\)C to 0.7 k\(\Omega\) at 100 \(^\circ\)C.

    Model: predict \(T\) from \(x = \ln R\) with a polynomial: \(T = \beta_0 + \beta_1x + \dots + \beta_dx^d\)

    Physics (the \(B\)-parameter equation) says \(1/T_K\) is linear in \(\ln R\), so \(T\) is a smooth curve in \(\ln R\). A polynomial in \(\ln R\) is still linear in the coefficients (Lecture 2).

    Question: which degree \(d\)?

    Too low underfits; too high fits the noise (Lecture 1). We need the test error of each degree, but have only 40 readings.

    Plot: 10 k\(\Omega\) at 25 \(^\circ\)C; 0.7 k\(\Omega\) at 100 \(^\circ\)C. Log scale

    Symbols

    \(R\)Resistance (k\(\Omega\)).
    \(T\), \(T_K\)Temperature in \(^\circ\)C; in kelvin, \(T_K = T + 273.15\).
    \(x\)\(\ln R\), the input.
    \(d\)Degree of the polynomial.
    \(B\)Thermistor constant (3950 K here).

    Worked numbers

    At 100 \(^\circ\)C: \(R = 10\exp[3950(1/373.15 - 1/298.15)] = 10\exp(3950 \times (-0.000674)) = 10\exp(-2.662) = 0.70\) k\(\Omega\).

    The validation set approach#

    1. Split the data at random into two halves. 2. Fit on the training half. 3. Measure the MSE on the validation half

    The simplest idea: hold back part of the data and use it as a test set.

    Plot: ten different random splits of the same 40 readings

    Each curve is the validation MSE against degree for one split. All agree that degree 1 is bad (MSE about 7), but they disagree about the rest.

    Two problems: the answer depends on the split: 10 splits pick degrees from 2 to 9. Only half the data are used for fitting

    With 20 validation points, the estimate is noisy: the best degree in the 10 splits was 5, 3, 2, 8, 4, 3, 9, 3, 2, 3. And a model fitted on 20 points is worse than one fitted on 40, so the validation error overestimates the error of the final model.

    The two words are easily confused. A validation set is used to make a choice (which degree), so it influences the final model. A test set only reports how good the final model is, and is never used to choose anything (slide 23).

    Leave-one-out cross-validation (LOOCV)#

    1. Leave out reading 1. Fit on the other \(n - 1\). 2. Predict reading 1: error \(\mathrm{MSE}_1\). 3. Repeat for every reading

    Each reading takes a turn as a one-point test set.

    \(\mathrm{CV}_{(n)} = \frac1n\sum_i \mathrm{MSE}_i\)

    The average of the \(n\) squared prediction errors. Here \(\mathrm{MSE}_i = (y_i - \hat y_{(-i)})^2\), where \(\hat y_{(-i)}\) is the prediction from the model fitted without reading \(i\).

    Good: every fit uses almost all the data. No randomness: always the same answer

    Bad: \(n\) fits. Slow for big data or slow models

    For least squares there is a shortcut that needs only one fit (ISLP equation 5.2), but not for most other methods.

    “\((-i)\)” means “with point \(i\) removed”.

    Symbols

    \(n\)Number of data points (40).
    \(\mathrm{MSE}_i\)Squared error on point \(i\) when it is left out.
    \(\mathrm{CV}_{(n)}\)LOOCV estimate of the test MSE.

    \(k\)-fold cross-validation#

    1. Split the data into \(k\) groups (folds). 2. Leave out fold 1; fit on the rest; compute \(\mathrm{MSE}_1\) on fold 1. 3. Repeat for every fold

    A compromise between the validation set (\(k = 2\), used once) and LOOCV (\(k = n\)).

    \(\mathrm{CV}_{(k)} = \frac1k\sum_j \mathrm{MSE}_j\)

    Usual choice: \(k = 5\) or \(k = 10\)

    With \(k = 10\) and \(n = 40\), each fit uses 36 points and each fold tests 4.

    Diagram: \(k = 5\). Red: left-out fold. Blue: used for fitting

    Every point is left out exactly once.

    Note the clash of letters: ISLP uses \(K\) for both the folds and the neighbours of KNN.

    Symbols

    \(k\)Number of folds.
    \(\mathrm{MSE}_j\)MSE on fold \(j\) when it is left out.

    Example: the 5-fold cross-validation estimate#

    A thermistor model is fitted 5 times, each time leaving out one fold. The MSEs on the left-out folds are 0.41, 0.38, 0.52, 0.45 and 0.39 °C². What is the cross-validation estimate of the test MSE, and how many model fits did it cost? How many would LOOCV cost with \(n = 60\) readings?

    Solution triple-click to reveal
    \[ \mathrm{CV}_{(5)} = \frac{1}{5}(0.41 + 0.38 + 0.52 + 0.45 + 0.39) = 0.430\ ^\circ\mathrm{C}^2. \]

    It cost 5 fits. LOOCV leaves out one reading at a time: 60 fits (for least squares there is a shortcut formula, but not for most methods).

    Thermistor: cross-validation picks the degree#

    Plot: training, LOOCV, 10-fold CV and true test MSE against degree

    Because the data are simulated, we can also compute the true test error on 5000 new readings, and check how well CV estimated it.

    Training MSE keeps falling

    From 6.64 at degree 1 to 0.17 at degree 8: more flexibility always fits the training data better. (At degree 10 even the training MSE rises, to 0.93: \(x^{10}\) is so large that rounding errors spoil the least-squares solve.)

    LOOCV and 10-fold CV both pick \(d = 3\) (MSE 0.25)

    LOOCV 0.254, 10-fold 0.253.

    The true test MSE, from 5000 new readings, is also lowest at \(d = 3\) (0.34)

    CV chose correctly. The level differs a little (0.25 versus 0.34) because 40 points give a noisy estimate, but the shape and the minimum agree.

    CV finds the right model without a separate test set

    Worked numbers

    Irreducible error: the reference noise is 0.5 \(^\circ\)C, variance 0.25; the 1% noise on \(R\) adds about \((0.01 \times \vert \mathrm{d}T/\mathrm{d}\ln R\vert )^2\), with \(\vert \mathrm{d}T/\mathrm{d}\ln R\vert = T_K^2/B = 323^2/3950 = 26\) K at 50 \(^\circ\)C, i.e. \((0.26)^2 = 0.07\). Total about 0.32, close to the best test MSE of 0.34.

    Which \(k\)? And a warning#

    LOOCV vs 10-fold: LOOCV: less bias (each fit uses \(n - 1\) points) but more variance (the \(n\) fits are almost identical, so their errors do not average out). 10-fold: 10 fits instead of \(n\), and usually just as good

    The \(n\) LOOCV fits are almost identical, so their errors are highly correlated and their average is noisy. 10-fold CV is the standard choice (ISLP 5.1.4).

    Classification: use the error rate in each fold instead of the MSE

    Do every step inside the folds: if you choose inputs using all the data and then cross-validate, the CV error is far too optimistic. Every step that looks at \(Y\) — choosing inputs, scaling, tuning — must be repeated inside each fold

    The classic mistake (ESL 7.10.2): with 5000 random inputs and 50 samples, pick the 100 most correlated with \(Y\), then cross-validate: CV reports near-zero error on pure noise. The left-out fold had already been used to choose the inputs. In scikit-learn a Pipeline keeps every step inside the folds.

    The bootstrap#

    How uncertain is a number that has no SE formula?

    Lecture 2 gave SE formulas for regression coefficients. For most other quantities there is no formula.

    1. Draw \(n\) rows with replacement from the data. 2. Compute the number again. 3. Repeat \(B = 1000\) times. 4. The spread of the \(B\) values is the SE

    The idea: we cannot collect 1000 new datasets, but we can imitate them by resampling the one we have.

    With replacement: some rows appear twice or more, some not at all. Each bootstrap sample is a plausible “other dataset”

    On average a bootstrap sample contains about 63% of the distinct rows (notebook question 4).

    Example: the 50% vibration point of Lecture 3: \(v_{50} = -\hat\beta_0/\hat\beta_1\), where the fitted probability of a fault is 0.5. There is no simple SE formula

    It is a ratio of two estimates, whose errors are correlated.

    Symbols

    \(B\)Number of bootstrap samples.
    \(v_{50}\)Vibration at which the fault probability is 50%.

    Worked numbers

    Probability that a given row is never drawn in \(n\) draws: \((1 - 1/n)^n\); for \(n = 200\) this is \(0.995^{200} = 0.367 \approx e^{-1}\). So about \(0.367 \times 200 \approx 73\) motors are missing from each bootstrap sample, and 63% are present.

    Example: how many readings does a bootstrap sample miss?#

    A bootstrap sample draws \(n\) readings with replacement from \(n\). What is the probability that one given reading is never drawn, for \(n = 10\) and for \(n = 1000\)?

    Solution triple-click to reveal

    One draw misses it with probability \(1 - 1/n\); \(n\) independent draws all miss it with probability \((1 - 1/n)^n\).

    • \(n = 10\): \(0.9^{10} = 0.349\)
    • \(n = 1000\): \(0.999^{1000} = 0.368\), close to \(e^{-1} = 0.368\).

    So each bootstrap sample leaves out about a third of the readings (these are the “out-of-bag” readings used in Lecture 5).

    Bootstrap: the 50% vibration point#

    Histogram: 1000 bootstrap estimates. Dashed: the true value, 4.0

    Each bar counts how many of the 1000 refits gave a 50% point in that range.

    Result: estimate 4.24 mm/s; bootstrap SE 0.14 mm/s; \(v_{50} = 4.24 \pm 0.14\) mm/s

    The SE is the standard deviation of the 1000 values.

    95% interval (\(\pm\) about 2 SE): \([3.96, 4.51]\). The true value, 4.0, is inside

    The percentile interval: the 2.5% and 97.5% points of the 1000 values. It is close to \(4.24 \pm 2 \times 0.14 = [3.96, 4.52]\).

    The same recipe works for almost any number computed from data

    A median, a correlation, an AUC, a time constant.
