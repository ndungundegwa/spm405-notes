    Kernels#

    Example: a shaft orbit#

    Two proximity probes at right angles measure the position of a rotating shaft (\(x\), \(y\) in \(\mu\)m)

    Eddy-current proximity probes are standard on large turbines, compressors and pumps. Plotting \(y\) against \(x\) gives the shaft's orbit.

    Healthy shaft: stays near the centre. Unbalance or rub: swings far out, in any direction

    The direction depends on the moment of the reading; only the distance from the centre matters.

    Data: 300 training readings, 3000 test

    No straight line can do this#

    The boundary should be a circle

    Faults lie outside a ring, healthy readings inside. Any straight line cuts the ring in half.

    Idea: add new inputs, such as \(x^2\) and \(y^2\). In the new inputs the circle \(x^2 + y^2 = r^2\) is a straight line (a hyperplane)

    With inputs \(u = x^2\) and \(v = y^2\), the circle is the straight line \(u + v = r^2\).

    Enlarge the feature space: a linear boundary in the enlarged space is a curved boundary in the original space

    The same trick as adding \(x^2\) in Lecture 2

    Symbols

    \(r\)Radius of the boundary circle (\(\mu\)m).

    Kernels#

    linear\(\sum_j x_{ij}x_{kj}\)
    polynomial\(\bigl(1 + \sum_j x_{ij}x_{kj}\bigr)^d\)
    radial\(\exp\bigl(-\gamma\sum_j (x_{ij} - x_{kj})^2\bigr)\)

    The SVM only needs similarities between pairs of points, \(K(x_i, x_k)\). A kernel computes them directly, without building the new inputs

    The SVM solution can be written using only inner products between training points (ISLP 9.3.2). Replacing the inner product by a kernel is equivalent to working in an enlarged space, possibly an infinite-dimensional one, without ever computing it.

    Linear: \(\sum_jx_{ij}x_{kj}\). Polynomial: \((1 + \sum_jx_{ij}x_{kj})^d\). Radial: \(\exp(-\gamma\sum_j(x_{ij} - x_{kj})^2)\)

    The linear kernel is the ordinary inner product (the support vector classifier). The polynomial kernel of degree 2 contains all products \(x_1^2\), \(x_2^2\), \(x_1x_2\). The radial kernel depends only on the distance between the two points.

    An SVM with a kernel is called a support vector machine

    Radial kernel: near points: similarity close to 1; far points: close to 0. Large \(\gamma\): very local, wiggly boundary

    Symbols

    \(K(x_i, x_k)\)Kernel: similarity of points \(i\) and \(k\).
    \(d\)Degree of the polynomial kernel.
    \(\gamma\)Width parameter of the radial kernel.

    Worked numbers

    Radial kernel with \(\gamma = 0.1\) (the value chosen by CV), in standardised units: points at distance 1 have similarity \(e^{-0.1} = 0.90\); at distance 3, \(e^{-0.9} = 0.41\); at distance 5, \(e^{-2.5} = 0.08\).

    Example: three kernels for the same pair of points#

    Compute \(K(\mathbf x, \mathbf x')\) for \(\mathbf x = (1, 2)\) and \(\mathbf x' = (2, 0)\) with the linear kernel \(\mathbf x\cdot\mathbf x'\), the polynomial kernel \((1 + \mathbf x\cdot\mathbf x')^2\) and the radial kernel \(\exp(-\gamma\|\mathbf x - \mathbf x'\|^2)\) with \(\gamma = 0.5\).

    Solution triple-click to reveal
    • Linear: \(1 \times 2 + 2 \times 0 = 2\).
    • Polynomial: \((1 + 2)^2 = 9\).
    • Radial: \(\|\mathbf x - \mathbf x'\|^2 = (1-2)^2 + (2-0)^2 = 5\), so \(K = e^{-0.5 \times 5} = 0.082\).

    The radial kernel is a similarity between 0 and 1: near 1 for close points, near 0 for distant ones.

    A near-circle around the healthy readings.

    Reading the shaft-orbit result#

    Linear methods are no better than guessing “healthy” (40% of readings are faults)

    Guessing “healthy” always is wrong for the 40% that are faults; logistic regression (0.375) and the linear SVM (0.403) are no better.

    Both kernels find a near-circle: the radial SVM's boundary has mean radius 33.5 \(\mu\)m

    The best possible rule, “fault if the distance from the centre exceeds 32.6 \(\mu\)m”, has error 0.055. The SVMs are almost there

    Because the classes overlap in radius (healthy up to about 35 \(\mu\)m, faults down to about 25), no rule can reach zero error.

    The radial SVM uses 68 of the 300 readings as support vectors

    If you know the physics, compute the radius yourself: \(r = \sqrt{x^2 + y^2}\). Then even logistic regression works. Kernels help when you do not know the right features

    Notebook question 5: logistic regression on \(r\) alone has test error 0.057, as good as the SVMs.

    Beyond the slide: overfitting with \(\gamma\)

    Notebook question 6: \(\gamma = 5\), \(C = 100\) gives training error 0.013 but test error 0.126. A very local kernel with expensive violations wraps the boundary around individual points.
