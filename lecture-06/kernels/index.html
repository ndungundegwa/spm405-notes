    Kernels#

    Some boundaries are not straight. This page shows how a support vector classifier can draw curved boundaries by working, implicitly, with extra inputs: the kernel trick. A support vector classifier with a kernel is called a support vector machine (SVM).

    Example: a shaft orbit#

    Large turbines, compressors and pumps carry two proximity probes at right angles. These eddy-current sensors measure the gap to the rotating shaft without touching it, giving the shaft's position \(x\), \(y\) in \(\mu\)m. Plotting \(y\) against \(x\) traces the shaft's orbit.

    • A healthy shaft stays near the centre.
    • With unbalance (mass off-centre) or a rub (the shaft touching a fixed part), it swings far out, in any direction.

    The direction depends on the moment of the reading; only the distance from the centre matters. Our data: 300 training readings and 3000 test readings, 40% of them faults.

    No straight line can do this#

    The boundary should be a circle: faults lie outside it, healthy readings inside. Any straight line cuts the circle in half, so every linear classifier fails.

    The remedy is the trick of Lecture 2: add new inputs, such as \(x^2\) and \(y^2\). With the new inputs \(u = x^2\) and \(v = y^2\), the circle \(x^2 + y^2 = r^2\) becomes the straight line \(u + v = r^2\). In general, enlarge the feature space: a linear boundary in the enlarged space is a curved boundary in the original space.

    Kernels#

    Adding many new inputs can be expensive. Fortunately, the support vector classifier never needs the inputs themselves: its solution can be written using only the inner products \(\sum_j x_{ij}x_{kj}\) between pairs of training points (ISLP Section 9.3.2), a measure of how similar two points are. A kernel \(K(x_i, x_k)\) replaces this inner product with another similarity. Doing so is equivalent to working in an enlarged feature space (possibly an infinite-dimensional one) without ever computing it. This is the kernel trick.

    kernel\(K(x_i, x_k)\)what it does
    linear\(\sum_j x_{ij}x_{kj}\)the ordinary inner product: the support vector classifier
    polynomial\(\bigl(1 + \sum_j x_{ij}x_{kj}\bigr)^d\)equivalent to adding all products of inputs up to degree \(d\); with \(d = 2\): \(x_1^2\), \(x_2^2\), \(x_1x_2\)
    radial\(\exp\bigl(-\gamma \sum_j (x_{ij} - x_{kj})^2\bigr)\)depends only on the distance between the two points

    The radial kernel gives a similarity between 0 and 1: close to 1 for nearby points and close to 0 for distant ones. The parameter \(\gamma\) sets how fast it falls with distance; a large \(\gamma\) makes the kernel very local and the boundary wiggly.

    Worked numbers

    Radial kernel with \(\gamma = 0.1\), in standardised units: points at distance 1 have similarity \(e^{-0.1} = 0.90\); at distance 3, \(e^{-0.9} = 0.41\); at distance 5, \(e^{-2.5} = 0.08\).

    Example: three kernels for the same pair of points#

    Compute \(K(\mathbf x, \mathbf x')\) for \(\mathbf x = (1, 2)\) and \(\mathbf x' = (2, 0)\) with the linear kernel \(\mathbf x\cdot\mathbf x'\), the polynomial kernel \((1 + \mathbf x\cdot\mathbf x')^2\) and the radial kernel \(\exp(-\gamma\|\mathbf x - \mathbf x'\|^2)\) with \(\gamma = 0.5\).

    Solution triple-click to reveal
    • Linear: \(1 \times 2 + 2 \times 0 = 2\).
    • Polynomial: \((1 + 2)^2 = 9\).
    • Radial: \(\|\mathbf x - \mathbf x'\|^2 = (1-2)^2 + (2-0)^2 = 5\), so \(K = e^{-0.5 \times 5} = 0.082\).

    The radial kernel is a similarity between 0 and 1: near 1 for close points, near 0 for distant ones.

    Shaft orbit: the result#

    \(C\) and \(\gamma\) were chosen together by 10-fold cross-validation over a grid of 20 combinations, \(C \in \{0.1, 1, 10, 100\}\) and \(\gamma \in \{0.01, 0.1, 0.5, 1, 5\}\). For the radial SVM this gave \(C = 10\), \(\gamma = 0.1\).

    Methodtest error
    Logistic regression0.375
    Linear SVM0.403
    Polynomial SVM, \(d = 2\)0.056
    Radial SVM0.060
    Best possible (rule on the radius)0.055
    • Linear methods are no better than guessing. Always guessing “healthy” is wrong for the 40% of readings that are faults; logistic regression (0.375) and the linear SVM (0.403) do no better.
    • Both kernels find a near-circle. The best possible rule, “fault if the distance from the centre exceeds 32.6 \(\mu\)m”, has error 0.055, and the SVMs are almost there. No rule can reach zero error, because the classes overlap in radius (healthy readings reach about 35 \(\mu\)m, faults come down to about 25 \(\mu\)m).
    • The radial SVM uses 68 of the 300 readings as support vectors.

    If you know the physics, compute the right feature yourself. Here that is the radius \(r = \sqrt{x^2 + y^2}\). Logistic regression on \(r\) alone has test error 0.057, as good as the SVMs. Kernels help most when you do not know the right features.

    Overfitting with a large \(\gamma\)

    \(\gamma = 5\) with \(C = 100\) gives a training error of 0.013 but a test error of 0.126. A very local kernel combined with expensive violations wraps the boundary around individual points.
