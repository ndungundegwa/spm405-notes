    Neural networks#

    With SVMs, splines and trees, a person chooses the inputs. Neural networks can start from raw measurements (pixels, samples of a signal) and build useful features themselves in their hidden layers. A network is assembled from pieces met in earlier lectures: linear models, the sigmoid, loss and cost, gradient descent and the ridge penalty. This page puts them together, explains how a network is trained (backpropagation), and shows how to stop it overfitting.

    A network with one hidden layer#

    A hidden unit (or neuron) \(k\) computes a linear model of the inputs and passes it through a non-linear activation function \(g\):

    \[ A_k = g\Bigl(w_{k0} + \sum_{j=1}^{p} w_{kj} X_j\Bigr). \]

    The numbers \(w_{kj}\) are its weights and \(w_{k0}\) its bias (intercept); they are learned from the data. The network's output is then a linear model in the hidden units (ISLP equation 10.1):

    \[ f(X) = \beta_0 + \sum_{k} \beta_k A_k . \]

    For classification, a sigmoid is applied to \(f\) to give a probability, as in logistic regression.

    The layer is called hidden because it is neither input nor output: we never observe the values \(A_k\).

    Example: a forward pass by hand#

    A network has 2 inputs, 2 hidden ReLU units and one linear output: \(h_1 = \mathrm{ReLU}(x_1 + 2x_2)\), \(h_2 = \mathrm{ReLU}(-x_1 + 0.5x_2 + 1)\), \(\hat y = 1.5h_1 - 2h_2 + 0.5\). Compute \(\hat y\) for \(\mathbf x = (0.5, -1)\). (ReLU is defined in the next section: \(\mathrm{ReLU}(z) = \max(0, z)\).)

    Solution triple-click to reveal

    \(h_1 = \mathrm{ReLU}(0.5 - 2) = \mathrm{ReLU}(-1.5) = 0\).

    \(h_2 = \mathrm{ReLU}(-0.5 - 0.5 + 1) = \mathrm{ReLU}(0) = 0\).

    \(\hat y = 1.5(0) - 2(0) + 0.5 = 0.5\). Both hidden units are switched off here, so only the output bias is left.

    Activation functions#

    Two activation functions matter most:

    • the sigmoid, \(g(z) = 1/(1 + e^{-z})\), from Lecture 3;
    • the ReLU (rectified linear unit), \(g(z) = \max(0, z)\): it passes positive values unchanged and sets negative ones to zero. It is fast and is the usual choice today. Its slope is either 1 or 0, which keeps training fast in deep networks, whereas the sigmoid's slope becomes tiny for large \(|z|\).

    Why must \(g\) be non-linear? A linear function of a linear function is linear. Without \(g\), a network would be just one big linear model, however many layers it had. The non-linearity is what lets the network bend and combine.

    Many layers#

    A deep network stacks hidden layers: each layer's outputs are the next layer's inputs. Early layers compute simple features; later layers compute combinations of them. (In image networks, early layers respond to edges and spots, later ones to shapes made of them.)

    The output layer depends on the task:

    • one unit with a sigmoid for a yes/no classification;
    • \(K\) units with a softmax for \(K\) classes (Lecture 3);
    • one plain unit (no activation) for regression.

    Counting parameters. A fully connected layer from \(a\) units to \(b\) units has \(a \times b\) weights plus \(b\) biases. For example, a network with 6 inputs, two hidden layers of 64 units, and 1 output has

    \[ \underbrace{6 \times 64 + 64}_{448} + \underbrace{64 \times 64 + 64}_{4160} + \underbrace{64 \times 1 + 1}_{65} = 4673 \text{ parameters}, \]

    against 7 for logistic regression on the same 6 inputs.

    Example: counting parameters#

    A network for the six-sensor machines has 6 inputs, a hidden layer of 32 units, a second hidden layer of 16 units, and 1 output. How many weights and biases does it learn? Compare with logistic regression on the same inputs.

    Solution triple-click to reveal

    Each layer has (inputs × units) weights plus one bias per unit:

    • 6 → 32: \(6 \times 32 + 32 = 224\)
    • 32 → 16: \(32 \times 16 + 16 = 528\)
    • 16 → 1: \(16 \times 1 + 1 = 17\)

    Total 769 parameters, against 7 for logistic regression. With a few hundred machines that is a lot: regularisation and early stopping matter.

    Fitting a network#

    A network is fitted like the models of Lectures 2 and 3:

    • Loss: squared error for regression, cross-entropy for classification.
    • Gradient descent, with two additions:
      • backpropagation, which uses the chain rule to compute the gradient of the loss with respect to every weight, working backwards from the output;
      • minibatches: each step uses a small random batch of rows (e.g. 64) instead of all the data. One pass through all the training data is an epoch; with 2000 rows and batches of 64, one epoch is 32 steps.

    Unlike linear and logistic regression, the cost is not a single bowl: it has many valleys, and different random starting weights (fixed by the seed) give different networks. There is no guarantee of finding the best answer, but in practice many valleys are about equally good.

    Backpropagation#

    “Backpropagation” sounds frightening, but it is the chain rule of calculus plus careful bookkeeping. Recall the chain rule: the derivative of \(f(g(x))\) is \(f'(g(x))\,g'(x)\). For example, the derivative of \((3x + 1)^2\) is \(2(3x + 1) \times 3\).

    One training step:

    1. Forward pass: feed a minibatch through the network, layer by layer, to get the predictions.
    2. Loss: compare the predictions with the true outputs.
    3. Backward pass: start at the output and go back layer by layer, using the chain rule to find how much each weight changed the loss: its gradient.
    4. Update: move every weight a small step against its gradient (gradient descent).
    5. Repeat with the next minibatch.

    For an output weight, the gradient is (error) \(\times\) (the hidden unit's value), just as in linear regression. For a weight one layer further down, the chain rule multiplies by the output weight and by the slope of the activation \(g\). Why “back”? A weight in an early layer affects the loss only through the later layers, so its gradient is built from the later layers' gradients, which are computed first and reused. The whole backward pass costs about as much as one forward pass (ISLP Section 10.7).

    Worked numbers: one forward and backward pass

    One input \(x = 2\), one hidden ReLU unit with weight \(w = 0.5\), output weight \(\beta = 3\), target \(y = 1\), loss \(\frac12(y - \hat y)^2\).

    Forward: \(A = \max(0, 0.5 \times 2) = 1\); \(\hat y = 3 \times 1 = 3\); loss \(= \frac12(1 - 3)^2 = 2\).

    Backward: \(\partial\text{loss}/\partial\hat y = \hat y - y = 2\); \(\partial\text{loss}/\partial\beta = 2 \times A = 2\); \(\partial\text{loss}/\partial w = 2 \times \beta \times g'(1) \times x = 2 \times 3 \times 1 \times 2 = 12\) (the ReLU's slope \(g'\) is 1 for positive input).

    In PyTorch, the most widely used deep-learning library, loss.backward() performs step 3 and optimizer.step() step 4. The usual optimiser is Adam, a version of gradient descent that adapts the step size for each weight from its recent gradients; it needs little tuning.

    Worked numbers

    16 hidden units: \(6 \times 16 + 16 = 112\), plus \(16 + 1 = 17\): 129 parameters. A network with no hidden layer and a sigmoid output has \(6 + 1 = 7\) parameters: it is exactly logistic regression, and gives the same test error, 0.149.

    Overfitting as training goes on#

    The training loss falls from 0.25 at epoch 10 to 0.004 at epoch 170. The test error is 0.097, 0.102, 0.113, 0.120 and 0.124 at epochs 10, 50, 90, 130 and 170: the longer the network trains, the more noise it fits.

    Early stopping uses this: keep back a validation set from the training data, and stop training when the error on it stops improving. (The plot uses the test set only to show the effect. In practice the validation set decides when to stop, and the test set is used once, at the end.)

    Regularising a network#

    Networks have many parameters, so they almost always need at least one of these:

    • Dropout: during training, switch off each hidden unit at random (here 30% of the time), so that no unit can rely on another. At prediction time all units are used, with their weights scaled to match. Dropout acts like training many thinned networks and averaging them, similar to bagging (Lecture 5).
    • Weight decay: add \(\lambda\sum w^2\) to the loss, where \(w\) runs over the weights and \(\lambda\) is the penalty strength. This is ridge regression (Lecture 4) for networks.
    • Early stopping: stop training when the validation error is lowest.
