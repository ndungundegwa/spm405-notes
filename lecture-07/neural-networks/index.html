    Neural networks#

    A network with one hidden layer#

    Diagram: inputs \(X_1, \dots, X_4\); hidden layer \(A_1, \dots, A_5\); output \(f\)

    Every input connects to every hidden unit, and every hidden unit to the output: a fully connected (dense) network.

    Each hidden unit \(k\): \(A_k = g(w_{k0} + \sum_jw_{kj}X_j)\): a linear model

    Each hidden unit computes its own linear combination of the inputs, then passes it through \(g\). The weights \(w\) are learned.

    The output adds them up: \(f(X) = \beta_0 + \sum_k\beta_kA_k\)

    The output is a linear model in the hidden units (ISLP equation 10.1). For classification, a sigmoid is applied to \(f\).

    \(g\) is a non-linear activation function. Hidden: neither input nor output; we never observe it

    Symbols

    \(X_j\)Input \(j\).
    \(A_k\)Activation (output) of hidden unit \(k\).
    \(w_{k0}, w_{kj}\)Bias and weights of hidden unit \(k\).
    \(g\)Activation function.
    \(\beta_0, \beta_k\)Bias and weights of the output.

    Example: a forward pass by hand#

    A network has 2 inputs, 2 hidden ReLU units and one linear output: \(h_1 = \mathrm{ReLU}(x_1 + 2x_2)\), \(h_2 = \mathrm{ReLU}(-x_1 + 0.5x_2 + 1)\), \(\hat y = 1.5h_1 - 2h_2 + 0.5\). Compute \(\hat y\) for \(\mathbf x = (0.5, -1)\).

    Solution triple-click to reveal

    \(h_1 = \mathrm{ReLU}(0.5 - 2) = \mathrm{ReLU}(-1.5) = 0\).

    \(h_2 = \mathrm{ReLU}(-0.5 - 0.5 + 1) = \mathrm{ReLU}(0) = 0\).

    \(\hat y = 1.5(0) - 2(0) + 0.5 = 0.5\). Both hidden units are switched off here, so only the output bias is left.

    Activation functions#

    Sigmoid: \(g(z) = 1/(1 + e^{-z})\) (Lecture 3). ReLU: \(g(z) = \max(0, z)\), the rectified linear unit. Fast, and the usual choice today

    ReLU passes positive values unchanged and sets negative ones to zero. Its gradient is 1 or 0, which keeps training fast in deep networks; the sigmoid's gradient becomes tiny for large \(\vert z\vert \).

    \(z\): the number that goes in (the linear model); \(\max(0, z)\): \(z\) if positive, otherwise 0

    Why non-linear? Without \(g\), a network is just one big linear model, however many layers it has

    A linear function of a linear function is linear. The non-linearity lets the network bend and combine.

    Many layers#

    A deep network stacks hidden layers: each layer's outputs are the next layer's inputs. Early layers: simple features. Later layers: combinations of features

    In image networks, early layers respond to edges and spots; later ones to shapes made of them.

    Output layer: one unit with a sigmoid for yes/no; \(K\) units with softmax for \(K\) classes (Lecture 3); one plain unit for regression

    The word “bias” now has two meanings in the course.

    Counting parameters: a layer from \(a\) units to \(b\) units has \(a \times b\) weights \(+ b\) biases

    6 inputs, 64, 64, 1 output: \(6 \times 64 + 64 = 448\); \(64 \times 64 + 64 = 4160\); \(64 \times 1 + 1 = 65\). Total 4673 parameters

    From 2000 training machines. Compare logistic regression: 7 parameters.

    Symbols

    \(a\), \(b\)Units in consecutive layers.

    Example: counting parameters#

    A network for the six-sensor machines has 6 inputs, a hidden layer of 32 units, a second hidden layer of 16 units, and 1 output. How many weights and biases does it learn? Compare with logistic regression on the same inputs.

    Solution triple-click to reveal

    Each layer has (inputs × units) weights plus one bias per unit:

    • 6 → 32: \(6 \times 32 + 32 = 224\)
    • 32 → 16: \(32 \times 16 + 16 = 528\)
    • 16 → 1: \(16 \times 1 + 1 = 17\)

    Total 769 parameters, against 7 for logistic regression. With a few hundred machines that is a lot: regularisation and early stopping matter.

    Fitting a network#

    Loss: squared error (regression) or cross-entropy (classification) — as in Lectures 2 and 3

    Gradient descent (Lecture 2), with two additions: backpropagation: the chain rule gives every gradient, working backwards from the output; minibatches: each step uses a small random batch (e.g. 64 rows). One pass through the data is an epoch

    Backpropagation is the chain rule organised efficiently: the error at the output is passed back layer by layer, giving the derivative of the loss with respect to every weight in about the cost of one forward pass (ISLP 10.7). With 2000 rows and batches of 64, one epoch is 32 steps.

    Not a single bowl: the loss has many valleys. Different starting weights (seeds) give different networks

    Unlike linear and logistic regression, there is no guarantee of the best answer. In practice many valleys are about equally good.

    Backpropagation in words#

    The name “backpropagation” frightens students. This slide shows it is the chain rule plus bookkeeping.

    1. Forward pass: feed a minibatch through the network, layer by layer, to get the predictions. 2. Loss: compare the predictions with the true outputs

    Exactly as for any model: predict, then measure the error.

    1. Backward pass: start at the output and go back layer by layer. The chain rule says how much each weight changed the loss: its gradient

    For an output weight, the gradient is (error) \(\times\) (the hidden unit's value), as in linear regression. For a weight one layer down, the chain rule multiplies by the output weight and by the slope of the activation \(g\). Each layer reuses the numbers already computed for the layer above.

    1. Update: move every weight a small step against its gradient (gradient descent). 5. Repeat with the next minibatch

    Why “back”: a weight in an early layer affects the loss only through the later layers. So its gradient is built from the later layers' gradients, which are computed first

    In PyTorch: loss.backward() does step 3; optimizer.step() does step 4. We use the Adam optimiser, a gradient descent that adapts the step size for each weight

    Adam adapts the step size for each weight from recent gradients; it needs little tuning.

    Worked numbers

    One input \(x = 2\), one hidden ReLU unit with weight \(w = 0.5\), output weight \(\beta = 3\), target \(y = 1\), loss \(\frac12(y - \hat y)^2\). Forward: \(A = \max(0, 0.5 \times 2) = 1\); \(\hat y = 3 \times 1 = 3\); loss \(= \frac12(1 - 3)^2 = 2\). Backward: \(\partial\text{loss}/\partial\hat y = \hat y - y = 2\); \(\partial\text{loss}/\partial\beta = 2 \times A = 2\); \(\partial\text{loss}/\partial w = 2 \times \beta \times g'(1) \times x = 2 \times 3 \times 1 \times 2 = 12\).

    Plot: training loss and test error against epoch, network 64 + 64, no dropout

    Recorded every 10 epochs.

    The training loss falls towards 0. The test error is lowest early (0.097 at epoch 10), then rises to 0.12

    Early stopping: keep back a validation set. Stop when its error stops improving

    We used the test set in the plot only to show the effect; in practice, a validation set taken from the training data decides when to stop, and the test set is used once at the end.

    Regularising a network#

    Dropout: during training, switch off each hidden unit at random (here 30% of the time). No unit can rely on another

    At prediction time all units are used (with weights scaled). Dropout acts like training many thinned networks and averaging them, similar to bagging (Lecture 5).

    Weight decay: add \(\lambda\sum w^2\) to the loss: ridge regression (Lecture 4) for networks. \(w\): the weights; \(\lambda\): penalty strength

    Early stopping: stop training when the validation error is lowest

    Networks have many parameters, so they almost always need at least one of these
