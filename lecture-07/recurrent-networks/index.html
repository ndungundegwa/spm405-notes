    Recurrent networks#

    Sequences: recurrent networks#

    Diagram: inputs \(x_{t-3}, \dots, x_t\); hidden states connected in a chain; forecast from the last

    A recurrent network reads a sequence one step at a time. Its hidden state \(h\) carries a memory of what came before, updated at every step with the same weights

    \(h_t = g(Wh_{t-1} + Ux_t + b)\): the new memory depends on the old memory and the new input (ISLP 10.5). The same \(W\), \(U\), \(b\) at every step: the weights are shared along time, as a CNN shares them across space.

    GRU and LSTM units have “gates” that decide what to keep and what to forget.

    Symbols

    \(x_t\)Input at time \(t\).
    \(h_t\)Hidden state (memory) at time \(t\).

    Example: forecasting a building's demand#

    The building of Lecture 5, metered every hour for 200 days. Task: from the last 24 hours, forecast the next hour

    Training: first 150 days. Test: last 50 days (1200 forecasts)

    \(50 \times 24 = 1200\) test hours.

    Demand follows the daily pattern, the weather, and disturbances that last a few hours

    Each hour's disturbance keeps 70% of the previous hour's, plus new noise (an AR(1) process).

    Split by time: for forecasting, never split at random: train on the past, test on the future

    A random split lets the model see hours just after the ones it predicts, which is impossible in use.

    Forecasting: the result#

    Methodtest MSE (kW\(^2\))
    Same hour yesterday45.8
    Linear, last 24 hours13.7
    Recurrent network (GRU)11.6
    Noise floor9.0

    Table: same hour yesterday 45.8; linear, last 24 hours 13.7; recurrent network (GRU) 11.6; noise floor 9.0

    The linear model is the autoregressive model AR(24): a linear regression on the last 24 values. Noise floor: the part no forecast can predict

    Plot: first 4 test days

    Both models follow the daily pattern closely; the GRU follows the disturbances a little better.

    The naive forecast ignores the current disturbance. The AR(24) model uses it. The GRU (929 parameters) does somewhat better still. No model can beat 9: the new noise each hour is unpredictable (notebook question 8). ISLP reaches a similar conclusion on stock-market data: RNNs help only modestly over a good linear AR model.

    Worked numbers

    GRU parameters: \(3 \times (16 \times 1 + 16 \times 16 + 16 + 16) = 3 \times 304 = 912\), plus the output \(16 + 1 = 17\): 929.
